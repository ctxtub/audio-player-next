## 用例规格

- 前置条件/夹具：`{{GUEST_FRESH}}`；输入 `{{E2E_PROMPT_SMOKE}}`（见 通用符号表；任意固定短句）。
- 步骤：1) 输入并发送；2) 观察流式阶段；3) 等待完成与自动播放。
- UI 断言：用户气泡即时出现；流式文本增长；完成后助手消息含故事卡与「播放故事」按钮；无卡死的 sending 态。
- 音频/浏览器断言：完成后 ≤3s 内 `audio.paused=false`、`currentTime` 递增；浮窗出现（配置默认开启）。
- 网络/数据断言：`agent.interact`（SSE）成功；`tts.synthesize` 成功；完成 +1s 后 `chat.saveConversation` 落库且 `storyCard.audioUrl` 为空串。
- 清理：清空会话（聊天页「清空」）；清 cookie。
- 证据要求：`ui-streaming.png`、`audio.json`、`db.txt`。
