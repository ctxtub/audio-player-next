# UI 一致性与新建故事集入口

用户授权修复浏览器 review 的四项问题，并调整新建故事集按钮位置。本次仅处理这些界面问题，不新增产品内容或配置入口。

- 新建故事集移到顶部创作状态卡的集合名称旁，作为中性次操作；输入区仅保留发送。手机标题与按钮各占可伸展空间，长标题完整换行。复用原新建处理及草稿/在途确认、取消保护和请求去重；恢复未就绪或发送中禁用入口。
- 首页保留集合、连续状态、时长及剩余预算；启停和时长设置仍只在设置页。正文和故事卡预览长度不变。
- 手机滑块刻度分两行错开，首尾标签保持在卡片范围内；不减少可选时长，不改范围、步长和当前值。
- 桌面集合标题与操作区上下排列，避免按钮挤压标题；全部操作保留。
- 内容页播放操作统一蓝色、胶囊、触控高度、图标和字体；单篇使用播放/继续播放/重新播放/暂停，集合操作保留整集限定词。播放器主播放圆形按钮维持现有布局。
- 复用既有新建及故事库/创作旅程，执行 test:fast、隔离 production build 和 diff-check，再通过内置浏览器检查手机/桌面、亮/暗、正常长度故事与草稿取消/确认。证据存 ignored 目录，由主助手直接实现。
