# 客户端路由导航播放连续性

功能域：03-播放状态与内核一致性

## 用户目标

用户在应用内页面之间来回切换（包括浏览器前进后退）时，正在播放的故事不中断，三处播放镜像显示一致，不会因为切页面就重播或变乱。

## 前置条件

- 故事正在播放中（可从《首个故事生成、流式渲染与自动播放》后继续）。

## 操作步骤

1. 在聊天页、播放页、设置页之间往返循环两次。
2. 期间使用浏览器后退两次、前进两次。
3. 每一步都观察三处播放镜像与实际声音。

## 验收标准

- 全程音频不中断（`audio.paused=false`，`currentTime` 连续递增；同一音频元素，未被重建）。
- 三处播放镜像（浮窗、播放页、故事卡）显示一致；后退与前进不产生重复挂载或状态抖动。
- 导航期间不产生重复的语音合成请求，也不产生集中的配置读取请求。

## 边界与异常

- 客户端路由导航不重建播放宿主；硬刷新停止播放是另一条已知例外语义，见《硬刷新后播放停止》。
- 导航前后播放进度落库不受影响。
