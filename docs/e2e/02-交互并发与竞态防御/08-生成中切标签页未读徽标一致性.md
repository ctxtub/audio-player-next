# 生成中切标签页未读徽标一致性

功能域：02-交互并发与竞态防御

## 用户目标

故事生成过程中切到别的标签页，用户回来后能通过未读徽标发现新回复，不错过内容，播放也不中断。

## 前置条件

- 访客首次打开站点（无既有身份）。
- 当上游大模型响应变慢时（生成需要等待，便于在生成中途切页）。

## 操作步骤

1. 在输入框输入一句话并发送，等待流式生成开始。
2. 切换到设置页。
3. 在设置页等待生成完成，观察底部导航"聊天"是否出现未读徽标。
4. 返回聊天页，观察徽标变化、消息数量与播放状态。

## 验收标准

- 生成完成前，底部导航"聊天"出现未读徽标。
- 进入聊天页后，未读徽标清除。
- 聊天消息不重复。
- 生成完成触发的自动播放跨页面保持，不因切页而停止。
- 生成完成的回调只生效一次。

## 边界与异常

- 切换标签页不中断生成；生成在后台继续，完成后行为与停留在聊天页一致（徽标提醒加自动播放）。
- 若生成失败，失败标记与重试行为见《失败消息重试上下文正确性》。
