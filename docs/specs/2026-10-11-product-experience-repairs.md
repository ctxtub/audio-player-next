# 创作保护与收听体验修复

## 目标与范围

依据 2026-10-11 内置浏览器验收，修复未发送草稿丢失、恢复播放显示不可信，以及控制和管理范围不易发现的问题。保留现有正式作品、播放会话、连续创作预算和访客迁移契约，不扩展账号、生成供应商或发布流程。

## 用户可见验收标准

- 有未发送输入或未保存内容时，新建故事集必须先确认。取消、Escape 或关闭对话框保留输入、当前身份和播放；确认后才执行原有强重置。无风险新建不额外确认。
- 刷新后保留暂停状态；播放准备前展示已保存位置与已知时长，未知时长使用占位，不显示伪造的零总长。加载完成后切换到真实媒体进度，不覆盖合法断点。
- 已知时长在列表、正文与播放器采用一致的秒级表达；不足一分钟不向上显示为一分钟。不得为迎合 mock fixture 修造真实时长。
- 创作页可直接开启或停止连续创作、调整自动播放时长，与设置页使用同一配置并明确提示同步关系，不另建独立偏好。复用已有服务入口与允许时长；说明暂停和准备不计时、到期停止。改变时长保留已消耗预算，耗尽后仍需显式重置。此条取代 2026-10-08 时长契约中“设置页唯一启停入口”和“创作页不提供开关”的限制，其余预算与恢复规则继续适用。
- 首次引导以选主题、生成、收听的用户目标解释功能；减少内部 Agent 术语。
- 收藏及回收站的故事集/单篇范围有明确选中态，并记住本次登录的范围选择。显式 URL 范围优先。展示真实计数时必须与当前筛选口径一致，不将分页长度伪装成总数。
- 访客提示按现有 cookie、清理和注册迁移机制准确说明保留条件；音色缺失属性不显示“未知 · 未知”。关键设置说明使用既有可读性 token。

## 实施与验证

同一工作区按创作、播放、故事库与设置分配不相交所有权。各实现者只做窄验证，不自行批准。主协调者负责集成、文档和最终门；实现静默后运行 test:fast、隔离生产 build、git diff --check，再以可见 UI 执行受影响的交付旅程。由不同子代理交叉只读审查，修复返回原实现者。
