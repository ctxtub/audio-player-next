# 旧播放器物理退役与音频归属（M9-02）

功能域：09-旧播放器退役与兼容收口

## 用户目标

旧 Player UI 物理消失：`app/(main)/player/` 只剩 `page.tsx`（M9-01 冻结 `redirect('/library')`）；旧书签 / 直接地址栏 / 刷新 / restored pathname=`/player` 行为与 M9-01 一致（全部落到 `/library`，会话经冻结 Anchor 连续，不伪造）；全局音频归属唯一收敛于 `AudioControllerHost`，M6 Mini / M7 Expanded 只做 consumer，M8 Canonical Work 播放与 Draft  ephemeral 语义不回归。

## 前置条件

- M9-01 CLOSED / FROZEN：`/player` 只剩 redirect `page.tsx`，旧 UI 不可达。
- 本项删除范围（物理删除）：`app/(main)/player/index.tsx`、`index.module.scss`、`components/PlaybackStatusBoard/**`、`components/GenerationPreview/**`、`components/AudioPlayer/**`。
- 保留：`app/(main)/player/page.tsx`（`redirect('/library')` 形式冻结，不改）。
- 禁止项：不碰 FloatingPlayer compat alias（`components/FloatingPlayer/index.tsx`）/ `playbackProgressStore` / legacy playback tRPC procedures / M5 schema / P3B / M10 browser debt / canonical audio。

## 操作步骤

1. 直接导航 `/player`（可带任意 query/hash，如 `/player?legacy=1#frag`）：断言 pathname=`/library`，`library-page` 可见，旧 Player 地标（`播放进度` slider / `播放速度` / `从头重播`）计数为 0，全程 URL 不含 `/player`（沿用 M9-01 L3 `player-compat-redirect` 语义，本项不新增 L3，只做静态锁 + 定向回归）。
2. 静态确认 `app/(main)/player/` 除 `page.tsx` 外无其他产品实现（L1 oracle P1）。
3. 静态确认全仓 active references：`PlaybackStatusBoard` / `GenerationPreview` / player-components `AudioPlayer` → 0（L1 oracle P2，注释剥离后匹配，只计 `.ts/.tsx` 产品代码 `app/components/lib/stores`，不计 `docs/specs/plans/tests` 历史引用与注释提及）。
4. 静态确认旧 Player 的“配置校验跳 `/setting`” `useEffect` 一并消失；`/player` 永远先 redirect（L1 oracle P3：`app/(main)/player/**` 无 `useEffect/useRouter/router.push('/setting')`，`page.tsx` 仍为最薄 server `redirect('/library')`）。
5. 静态确认全仓 audio owner（L1 oracle P4）：旧 `AudioPlayer` 不存在 + 正式 `AudioControllerHost` ownership 保持（唯一全局 `<audio>` owner；`playbackStore`=transport only（`registerAudioController`）；`PlaybackSessionStore`=Session SSOT；Mini/Expanded=consumers 经 Flow/facade 消费，不得在 NowPlaying 再造第二个 `<audio>`）。
6. 静态确认 HistoryPanel：不新增删除工作；`app/(main)/player/**` 无 History ownership，正式实现仍在 `app/(main)/chat/components/HistoryPanel`（M4 Chat 所有，L1 oracle P5）。
7. 定向 browser 回归（既有 spec，不新增 L3）：M6 Mini `main-chrome-mobile-docked`（play/pause/openExpanded）+ M7 Expanded `expanded-playback-capabilities`（seek/rate）/ `expanded-sleep-timer`（timer）/ `creation-actions`（actions）+ M8 `canonical-work-playback`（Work canonical 播放/重播）/ `canonical-closure`（生产收官）+ M9-01 `player-compat-redirect`（redirect 不回归），chromium+webkit。

## 验收标准

- `app/(main)/player/` 只含 `page.tsx`；`index.tsx` / `index.module.scss` / `components/PlaybackStatusBoard` / `components/GenerationPreview` / `components/AudioPlayer` 物理不存在。
- 全仓 active product code（`app/components/lib/stores` 下 `.ts/.tsx`，注释剥离）：`player/components/` 导入路径 0 处；`const PlaybackStatusBoard` / `const GenerationPreview` / legacy `const AudioPlayer` 组件定义 0 处。
- 旧 `/setting` 校验跳转消失：`app/(main)/player/**` 无 `useEffect`、`useRouter`、`/setting`；`page.tsx` 仍精确 `redirect('/library')`（server 组件，无 `use client`，无 query/hash 透传，无 Session/Anchor/transport 碰触）。
- Audio 唯一 owner：`components/AudioControllerHost/index.tsx` 存在且含唯一 `<audio>`（全仓产品代码注释剥离后 `<audio` 计数=1）；`components/NowPlaying/**` 计数=0；`stores/playbackStore.ts` 含 `registerAudioController`（transport）；`stores/playbackSessionStore.ts` 存在（Session SSOT）；Mini 经 `playbackSessionFlow` + 双 store 消费，Expanded 经 facade 消费。
- HistoryPanel：`app/(main)/player/**` 零 ownership；`app/(main)/chat/components/HistoryPanel/index.tsx` 存在（M4 正式实现，不机械删除别处同名）。
- 回归：上述定向 browser spec 全绿（chromium+webkit，`retries=0`）；unit / integration / tooling / catalog / tsc / lint / build / prisma validate 不 regress。

## 边界与异常

- `redirect('/library')` 为 server 侧，不先闪旧 Player，不依赖 hydration；本项不改其形式（M9-01 冻结）。
- 不自动跳 `/library/[lastPlayingWorkId]`：`/player` 不是作品 deep link。
- FloatingPlayer compat alias（`components/FloatingPlayer/index.tsx` deprecated shim）、`playbackProgressStore`（M5-09 deprecated adapter）、legacy playback tRPC procedures、M5 schema/identity、P3B、M10 browser debt、canonical audio 一律不动，留后继项清理。
- M5 schema/identity、AccountSync hydrate、Anchor 恢复链冻结语义不变。
- 历史文档（`docs/specs/**`、`docs/plans/**`、M9-01 `01-….md`、DESIGN_SPEC 遗留描述）中的旧组件提及为历史快照，不计入 active references，不在本项改写。
