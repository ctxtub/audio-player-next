# 故事库完整生命周期旅程

功能域：07-故事库与作品资产

## 用户目标

用户在真实浏览器中完整经历故事库全生命周期：在海量作品列表中体验首屏截断与滚动自动分页加载、通过关键词搜索即时过滤、从卡片进入真实详情页、在详情中重命名标题并验证列表跨缓存无缝同步、切换收藏状态并在收藏视图中精准呈现、在详情页执行移入回收站并验证页面自动导航离开及 Undo 撤销即时恢复、验证回收站卡片严格无详情入口且直接访问触发统一不可用保护、在回收站恢复作品至全部列表、再次软删除后触发永久删除二次确认弹窗、以及作品彻底物理删除后在全部视图、收藏视图、回收站视图与直接访问路径下的彻底不可逆消失。

## 前置条件

- 服务可用，数据库已执行必要迁移。
- 采用真实注册用户身份（`ensureRegisteredByApi`），具备独立且洁净的数据空间与充足的 API 速率配额（authedLimit = 60）。
- 通过真实 API 批量创建 >=21 条真实故事作品（如 22 条），确保跨越首屏默认单页限额（20 条）。

## 操作步骤与生命周期旅程

1. **批量作品准备（>=21 条）**：通过真实 tRPC 创作接口预先创建 22 条作品，其中第 22 条为具备特定关键词的目标作品（如“小猫历险记”）。
2. **访问故事库主页首屏验证**：访问 `/library` 全部（active）视图，确认首屏仅渲染 20 条卡片，分页哨兵组件（InfiniteScrollSentinel）就绪。
3. **滚动加载下一页**：滚动触达底部哨兵，触发第二页拉取，确认列表增量加载至 22 条，并呈现“— 没有更多了 —”终态提示。
4. **搜索过滤（q 查询）**：在工具栏搜索框输入关键词“小猫”，验证输入防抖过滤后仅呈现目标作品卡片，清空搜索后恢复全量 22 条。
5. **进入真实详情页**：点击目标作品卡片标题链接，导航至 `/library/{真实id}`，确认详情容器与标题正确渲染。
6. **重命名并验证跨缓存同步**：在详情页点击重命名，修改标题为“勇敢小猫大冒险”并保存；点击返回故事库，确认列表视图中同 ID 作品卡片标题同步更新。
7. **详情页收藏作品**：再次进入该作品详情页，点击收藏按钮，确认收藏高亮徽标展示与状态变更。
8. **返回列表并切换收藏视图**：返回列表并切换至“收藏”Tab，确认目标作品出现在收藏列表中。
9. **详情页移入回收站并离开**：再次进入详情页，点击“移入回收站”按钮，确认页面自动导航离开并重定向至 `/library`，同时激活全局撤销浮条（LibraryUndoToast）。
10. **执行 Undo 撤销恢复**：点击撤销浮条上的“撤销”按钮，等待恢复完成，确认作品立即重新回到全部列表。
11. **第二次移入回收站**：在列表卡片上点击“移入回收站”，确认卡片从全部列表中移出，撤销浮条再次弹出后关闭。
12. **切换至回收站视图**：在工具栏点击“回收站”Tab，确认目标作品出现在回收站列表中，并标有“已移入回收站”状态。
13. **回收站卡片无详情入口验证**：检查回收站中目标作品卡片，确认标题为纯文本而非链接，整张卡片绝无任何指向 `/library/{id}` 的 `<a>` 标签；若直接在地址栏访问 `/library/{id}`，严格呈现统一不可用界面（`LibraryUnavailable`）。
14. **从回收站恢复作品**：在回收站卡片上点击“恢复”按钮，确认作品从回收站列表中移除；切换至“全部”视图，确认作品恢复可见。
15. **第三次移入回收站**：在全部列表再次点击该作品卡片“移入回收站”，作品移入回收站；切换至“回收站”Tab 确认其存在。
16. **永久删除二次确认流**：在回收站卡片点击“永久删除”，确认弹出二次确认模态对话框；点击对话框内的“永久删除”确认按钮，完成物理删除。
17. **全维度彻底消失验证**：
    - 回收站列表无该作品；
    - 切换“全部”列表无该作品；
    - 切换“收藏”列表无该作品；
    - 直接访问 `/library/{id}` 呈现统一不可用视图（`LibraryUnavailable`），绝不展示任何作品数据。

## 验收标准

- 所有数据流转全量走真实 API 与真实 DOM 事件，严格零 mock 核心逻辑。
- 首屏 20 条与滚动加载 22 条行为完全符合服务端游标分页与无限滚动契约。
- 详情修改（Rename）后列表标题立即就地一致同步，且 opaque 分页元数据保持无损。
- 详情软删除触发自动导航离开（离开 `/library/[id]`），Undo Toast 跨路由生命周期留存且支持安全撤销。
- 回收站视图中严格杜绝 Detail 入口；直接访问软删除/已删除作品路由严格呈现统一不可用页面，杜绝存在性探测。
- 永久删除严格遵循二次确认流，未确认前零网络请求，确认后不可逆物理清除。
- 全程控制台无未捕获异常与系统级报错。
