# Onboarding 首访标记与未读跨会话

功能域：04-云端存储与多端数据调和

## 用户目标

新访客第一次进入聊天页时看到一次新手引导，之后刷新、开新标签页、再次访问都不再打扰；有新消息时底部导航「聊天」出现未读徽标，进入聊天后清除；切换账号后不复用旧账号的未读标记。

## 前置条件

- 全新访客身份（首访）。
- 同一浏览器复用同一身份（回访共用本地存储）。

## 操作步骤

1. 首次进入 `/chat`，观察新手引导。
2. 关闭引导后刷新页面，观察引导是否再次出现。
3. 在新标签页打开同会话，观察引导是否再次出现。
4. 停留在 `/setting` 时等待一次收到的消息完成，观察底部导航「聊天」徽标；随后返回聊天页，观察徽标变化。

## 验收标准

- 新手引导仅首次出现：刷新、新标签页、回访都不再弹（标记存于 localStorage，键名 `chat_onboarding_seen_v1`，跨标签页共享）。
- 未读徽标在有未读时出现，进入聊天后清除。
- 徽标清除不复用其他身份的旧标记：切换账号后重新计算。

## 边界与异常

- 首访标记只记在本地浏览器中：换浏览器或清除本地存储后会再次出现。
- 生成中切换标签页时的徽标时序行为见《生成中切标签页未读徽标一致性》。
