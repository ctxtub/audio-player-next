# 登出→双 cookie 清理与数据清空

功能域：05-认证授权与会话生命周期

## 用户目标

已登录用户退出登录后，回到干净的未登录页：个人数据从界面上全部消失，登录态标识全部失效，他人用后退按钮也看不到已登出的数据。

## 前置条件

- 账号 A 处于登录态；故事正在播放中（播放停止的时序细节见《播放中登出立即停声与状态重置》）。

## 操作步骤

1. 在设置页（`/setting`）点击「退出登录」。
2. 观察落点页面与浏览器中的登录态标识。
3. 读取配置、聊天、历史、进度四处界面数据。
4. 使用浏览器后退，观察是否会恢复已登出的数据。

## 验收标准

- 登出后跳转到登录页（`/auth`）。
- 配置、聊天、历史、进度四处界面数据全部清空。
- 退出登录的响应同时让登录态标识与访客标识失效（两个身份标识同时清除）。
- 登出后浏览器后退不得恢复已登出的数据（客户端路由状态重建）。
- 登出后直接访问受保护页面会被送回登录页（携带来源参数）。

## 边界与异常

- 登出后没有声音残留；播放停止的时序要求见《播放中登出立即停声与状态重置》。
- 登出后再以访客进入会得到全新身份，见《登出后再入访客的新身份隔离》。

## 实现参考

- `lib/trpc/routers/auth.ts`（登出时同时清除双身份标识）
- `stores/authStore.ts`（登出成功后回到未登录态）
- `stores/accountSync.ts`（登出清空账号数据）
