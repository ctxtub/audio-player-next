# 故事库三层页面视觉与交互重构（纯矢量 SVG 专辑封面与沉浸阅读）

- 日期：2026-10-18
- 状态：Implemented

## 1. 背景与目标

故事库（`/library`、`/library/collections/[id]`、`/library/collections/[id]/works/[workId]`）在完成基础功能收敛后，仍存在以下体验短板：

1. **故事库列表页（`/library`）**：纯文本纵向卡片缺乏有声故事集识别度；桌面端强行锁死窄单列浪费视口；卡片底部主按钮固定为“从头开始”，缺乏断点续播与上次伴听感知。
2. **故事集详情页（`/library/collections/[id]`）**：移动端章节行拆分为上下两层高行，行尾直接暴露红色删除图标易引发滑动误触；“续写新章节”被埋在曲目列表最底部；缺乏明确的“正文”阅读视觉引导。
3. **单篇故事正文页（`StoryDetail`）**：“管理故事”与标题争抢水平空间；音色直接暴露技术 ID（如 `zh-CN-YunxiNeural`）；缺少集合内上下章快速切换能力。
4. **视觉规范约束**：全站故事库严禁使用任何 Emoji 充当图标或封面，所有图标与插画必须采用真实矢量 SVG（`lucide-react` 与多图层矢量渐变插画 `CollectionCoverArt`）。

## 2. 核心设计变更

### 2.1 纯矢量 SVG 故事集封面组件（`CollectionCoverArt`）
- 基于故事集标题与 ID 确定性映射 6 套多层矢量 SVG 主题插画（星夜灯塔、迷雾松林、星轨弯月、暮色列车、深海声波、暖炉故事书）。
- 零 Emoji，采用 SVG `linearGradient` / `radialGradient`、几何光影路径与播放态动态声波指示器。

### 2.2 故事库列表页（`/library`）
- **继续伴听聚光横幅（Continue Listening Spotlight）**：在“全部”视图顶部自动浮现当前播放或最近有未听完进度的故事集，支持一键继续伴听或进入详情。
- **横向专辑卡片（`CollectionCard`）**：左图（SVG 专辑封面）+ 中部（标题、简介、篇章数与状态胶囊）+ 右侧（智能播放/继续播放/暂停胶囊按钮），移除低效的卡片底部分割线。
- **响应式书架网格**：移动端单列紧凑呈现，桌面端（`>= 860px`）自动切换为双列 Bento 书架网格（最大宽度 `1080px`），工具栏与页头同行对齐。

### 2.3 故事集详情页（`/library/collections/[id]`）
- **专辑英雄区升级**：左侧展示大尺寸矢量 SVG 封面，统计行聚合总篇章数与总时长；主操作区提权整合 `[继续播放]`、`[续写新章节]` 与 `[从头播放]`，顶部导航栏提供 `[查看创作记录]`。
- **紧凑单行章节目录**：移动端与桌面端统一保持单行网格布局（序号/动态声波 + 标题/进度微条 + `[正文]` 阅读入口 + 播放状态胶囊），移除行级外露删除按钮以防误触。

### 2.4 单篇故事阅读页（`StoryDetail`）
- **管理入口上移**：将“管理故事（重命名/删除）”收入顶部导航栏右侧，释放标题区 100% 宽度。
- **友好化元数据与内嵌伴听条**：将技术音色 ID 映射为自然中文名称（如 `云希 · 温暖男声`），并将播放控制按钮、音频状态与矢量声波纹理整合为内嵌伴读音频条。
- **章节连贯切换**：正文底部新增“上一章 / 目录 / 下一章”快速切换导航卡。
