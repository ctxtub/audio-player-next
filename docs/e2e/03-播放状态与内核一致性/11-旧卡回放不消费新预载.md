# 旧卡回放不消费新预载

功能域：03-播放状态与内核一致性

## 用户目标

用户回放旧故事卡时，新故事卡备好的预载不被误吃：旧卡播完不会突然蹦出新卡的后续内容，两卡文本不串台。

## 前置条件

- 访客首次打开站点。
- 有两张故事卡：旧卡 A 与新卡 B，其中新卡 B 已产生就绪的预载。

## 操作步骤

1. 让新卡 B 播放至临近段尾（此时预载就绪）。
2. 暂停。
3. 回放旧卡 A。
4. 把 A 播至临近段尾，观察 A 结束时的行为与预载状态。

## 验收标准

- A 结束时不得把 B 的预载内容当作 A 的下一段播放。
- A 结束后播放停止，或基于 A 的文本正确续写；不出现两卡文本串台。
- 只有当结束的卡片仍是最新一条故事卡时，才允许取用预载（`isLatestMessage` 门控：以"是否最新消息"为条件，决定本次结束能否消费预载）。回放旧卡 A 时该条件为否，因此预载保留、不被清空。

## 边界与异常

- 旧卡回放期间，新卡的预载保持就绪态，不被消耗也不失效。
- 切回新卡 B 继续播放时，仍可正常消费其预载。
