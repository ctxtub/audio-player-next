# 发送中建议项点击拦截

功能域：02-交互并发与竞态防御

## 用户目标

故事正在生成时，用户误触建议项不会打断当前生成，也不会丢输入框里的内容，当前回答完整不受影响。

## 前置条件

- 访客首次打开站点（无既有身份）。
- 故事正在流式生成中（当上游大模型响应变慢时更容易观察到本行为）。

## 操作步骤

1. 在输入框输入一句话并发送，等待流式生成开始。
2. 在生成过程中点击任一建议项。
3. 观察页面提示、输入框内容是否变化。
4. 等待生成结束，确认当前回答完整，聊天记录无异常新增。

## 验收标准

- 点击被拦截，并给出"正在生成回答"或等价提示。
- 输入框内容不被建议文本覆盖，保持点击前的原样。
- 不发起第二路生成请求。
- 不产生异常的会话保存。
- 被拦截的点击不产生任何副作用，聊天记录与输入框保持原样。

## 边界与异常

- 生成结束后再点击建议项，按正常发送流程处理。
- 若生成失败，失败标记与重试行为见《失败消息重试上下文正确性》。
