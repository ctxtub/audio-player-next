# M7 P3A 聚合收官与生产切流 M7-04-04

功能域：01-基础冒烟与页面基线

## 用户目标

M7 P3A 生产切流后，一次聚合旅程证明正常产品流不再经过 `/player`：Work 会话经 Mini → Expanded 完成段 timeline / 播放 / seek / 倍速 / 睡眠定时 UI / restart 可达 / 查看正文到 `/library/[workId]`；Draft 会话经 Mini → Expanded 完成查看正文 → Transcript → 返回 controls → 返回创作到 `/chat` 且零自动发送；全局生命周期（普通路由切换不关、关闭回 Mini、clear/idle 自动关、390 Sheet / 900 Panel、同 Session 连续）全程成立；静态侧由 L1 生产切流守卫锁定（allowlist 制零导航、`/player` 物理保留、deprecated 兼容保留）。

## 前置条件

- M5 PlaybackSessionStore（`source` 为 draft/work）/ playbackStore / AudioControllerHost ownership 冻结；Expanded 开关为纯 UI state（`nowPlayingUiStore.isExpanded`）。
- M7-01 Expanded Surface（普通路由切换不自动关闭，`§44`）、M7-02 P3A（本段时间轴 + 七档倍速 + restart，`§40` 无上一段/下一段）、M7-03 P3C（minutes/off/story_end 三态）、M7-04-01 Work 查看正文、M7-04-02 Draft Transcript、M7-04-03 返回创作边界全部冻结。
- 旧 `/player` 物理保留（M9 前不删除/不 redirect）；M6 `router.push('/player')` 已替换为 `openExpanded()`；deprecated 兼容符号（`NOW_PLAYING_COMPAT_ROUTE` 等）保留至 M9。
- Timer 到期 / speed 去重 / restart 失败等深边界已有 targeted 锁（本聚合不重新穷举，只做 UI 可达与同一性）。

## 操作步骤

1. 注册新用户并建 Work 作品（真实 `library.create`，两段正文），经探针 `beginWork(resume)` + 首段合成 + pause 驻留，视口 390×844，记录 `sessionId/source/audioUrl/audioCount` 与访问 URL 集合（全程断言不含 `/player`）。
2. Work 旅程：点 Mini 元数据开 Expanded（URL 不变，session 不变）→ 断言段 timeline（`expanded-timeline` + `本段` + 段落 badge）存在 → Play/Pause 各一次（状态翻转且 session 不变）→ timeline 75% 点击 seek（时间跳变，session 不变）→ 倍速菜单选 1.5x（Session + Transport 同步，不写默认配置）→ 睡眠定时 pill 可见并开菜单见 off/10/story_end（只做 UI 可达，不做到期穷举）→ restart 按钮可见可达（只断言可达与点击后 session 语义，不穷举失败）→ 点「查看正文」先关后导精确 `/library/[workId]`（播放继续，Host 不重挂）。
3. 普通路由 oracle（Work 会话上）：重开 Expanded 后经 TabBar 切 `/chat → /library`，Expanded 仍 open 且 session 不变（普通 route change ≠ close）。
4. 响应式 oracle：390 下为 Sheet（底锚全宽）→ 切 900 为 Panel（右锚约 400px）→ 回 390 仍 open（resize 不重置 `isExpanded`）。
5. 关闭 oracle：Escape 关闭 → Mini 恢复且 session/暂停态不变（close → Mini）。
6. Draft 旅程（同页内 seed，不建 server Anchor）：seed Draft 会话并 pause 驻留 → 点 Mini 开 Expanded（URL 不变）→ 点「查看正文」（Transcript 口）切 transcript（URL 不变，只读展示 storyText 原文）→ 点返回控制回 controls（session 不变）→ 点「返回创作」先关后导 `/chat`（session/暂停态/audio 不变，chat 消息数/input/pendingAutoSend 全不变，零自动发送）。
7. clear/idle oracle：经探针 clear（或 logout 等价）使 `source null / idle`，断言 Expanded 自动关闭且 Mini 不残留旧会话（clear/idle → auto-close）；全程 URL 集合无 `/player`。
8. 源码守卫（L1 `exec-production-cutover`）：审计 `components/**、app/(main)/**、lib/client/**、stores/**`（剥离注释后）除 allowlist 外零 `router.push('/player')` 等五形态；`app/(main)/player/**` 仍存在；deprecated 符号仍存在；NowPlaying 不依赖旧 AudioPlayer；不拼 continuation Prompt；UI Store 纯 UI。

## 验收标准

- Work 全链：Mini → Expanded → timeline 存在 → Play/Pause → seek → rate 1.5x → Sleep Timer UI 可见可开 → restart 可达 → 查看正文 → 精确 `/library/[workId]`，全程 session 同一性（除 restart 新 UUID 外）+ 无新增 `beginSession`/`tts.synthesize` + URL 从未进 `/player`。
- Draft 全链：Mini → Expanded → 查看正文 → Transcript 只读 → 返回 controls → 返回创作 → `/chat`，零自动发送（无 send/预填/追加），播放继续，全程 URL 从未进 `/player`。
- 全局生命周期：普通路由切换不关；close → Mini 恢复；clear/idle → auto-close；390 Sheet / 900 Panel；同 Session 连续（`sessionId` 跨开关/导航不变，restart 除外）。
- 不重新穷举 Timer 到期 / speed 去重 / restart 失败（targeted 已锁；本聚合只做可达与同一性）。
- Chromium + WebKit 双跑；`--repeat-each=2` 下稳定（确定性轮询，无长 sleep，`retries=0`）。

## 边界与异常

- 无 session 时 Mini 不渲染，Expanded 不可开（fail-closed）。
- duration 未知/0 时 seek 为 no-op，不抛错不换 session（P3A 既有语义）。
- 空 storyText Draft：Transcript 口隐藏但返回创作仍展示（解耦；与 M7-04-03 一致）。
- promotion（同 sessionId 切 work）不强制关 transcript（M7-04-02 语义）；本聚合以独立 Work/Draft 会话为主，不耦合 promotion 竞速。
- 慢沙箱一律确定性轮询（`expect.poll`），无长 sleep；双 project 串行、`retries=0`。
