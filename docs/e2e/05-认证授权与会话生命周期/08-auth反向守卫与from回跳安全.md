# 登录页反向守卫与来源回跳安全

功能域：05-认证授权与会话生命周期

## 用户目标

已登录用户误开登录页会被送回主页；从受保护页被拦到登录页的用户，登录后回到原来想去的页；来源参数指向站外时一律不跳出站（防开放重定向）。

## 前置条件

- 账号 A 处于登录态；另备一个无身份的干净会话。

## 操作步骤

1. 登录态直接访问登录页（`/auth`）。
2. 登录态直接访问带站内来源的登录页（如 `/auth?from=/setting`）。
3. 未登录访问设置页，被拦到登录页后完成登录，观察回跳。
4. 分别用站外来源（`//evil.example.com`、`https://evil.example.com`）打开登录页并完成登录。

## 验收标准

- 已登录访问登录页会被弹回聊天页（反向守卫）。
- 来源为合法站内路径时，登录成功后回到原路径（如设置页）。
- 来源为外部域或协议相对地址时，一律不跳往站外（落在站内页）；一旦跳出即视为最高优先级缺陷。
- 重定向只发生在网关中间层。

## 边界与异常

- 本场景覆盖"会话切换时序与来源安全"深度；三身份乘三页面的广度覆盖见《路由守卫与重定向安全》。
