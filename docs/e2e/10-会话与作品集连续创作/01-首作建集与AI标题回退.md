# 会话首作建集与 AI 标题回退

功能域：10-会话与作品集连续创作

## 用户目标

用户或具名访客在一个创作会话里完成第一份故事 Artifact 后，系统自动创建一个作品集（StoryCollection），并给出一句可读的标题；标题生成失败、超时或返回空值时，作品入库流程绝不被阻断，用户仍能拿到自己的作品，标题退回确定性短标题。

## 范围与边界声明

本场景覆盖 T1「Conversation / Collection 数据底座」的服务端行为（L1 + L2 隔离库严格断言）。
**明确排除以下后续能力**（属 T2/T3/T4，本用例不声称覆盖）：
- 创作页面的连续创作编排与「重置为全新创作」强语义（T2）；
- AudioAsset / 单轨播放 / 进度 / 缓存（T3）；
- Library 作品集列表 UI、Mini 安全区与契约迁移（T4）；
- 旧版本 Prompt/Generation History 的 UI/store/router 物理退役（T2）；T1 仅保证新路径零 History 写入并提供回退读开关。

## 契约验收标准

### 1. 首作建集（first work creates collection）
- Promotion 是 Artifact → Collection/Work 的唯一写入口：入参 `conversationId`、`sourceMessageId`、`prompt`、`storyText`、可选 `voiceId`。
- 同一 `conversationId` 下首次成功 promotion 时，必须创建**恰好一个** `StoryCollection`（User → `StoryCollection`，Guest → `GuestStoryCollection`），且该集合与该会话一对一（DB 层 `conversationId UNIQUE`）。
- 第二次及以后对同一 `conversationId` promotion 不得新建集合，只向既有集合追加成员。
- 不同 `conversationId` 各自拥有独立集合，绝不互相追加。

### 2. 集合内 position（deterministic in-collection position）
- 首作 `position = 0`；同会话第 n 份作品 `position = 当前集合最大 position + 1`，严格单调、无空洞、无重复（DB 层 `UNIQUE(collectionId, position)`）。
- `list`/`get` 读取成员时按 `position ASC, id ASC` 返回。

### 3. AI 标题短超时与确定性回退链（title timeout & fallback chain）
- 仅当该会话尚无集合时尝试 AI 标题；生成受注入式生成器与短超时（默认 1500ms）约束。
- 解析优先级：严格正文标题（`strictStoryTitle`）→ prompt 摘录（`buildCollectionFallbackTitle`）→ `未命名作品集`。
- 生成器抛错 / 超时 / 返回空 → 使用确定性回退标题，`titleSource` 为 `fallback`；生成成功 → `ai`。
- **标题失败绝不阻断 Work 入库**：即使生成器永不返回（超时），promotion 仍必须在超时后正常完成并成功返回 `StoryWorkDetailDTO`。
- 用户显式改名后 `titleSource = 'user'`，后续自动流程永远不得覆盖。

### 4. 幂等与冲突（sourceMessageId idempotency）
- 同主体 + 同 `sourceMessageId` + 同 `contentHash`：幂等返回既有 Work，**不新增行、不新增集合**。
- 同主体 + 同 `sourceMessageId` + 不同 `contentHash`：`CONFLICT`，绝不覆盖既有正文。
- 跨会话：同一 `sourceMessageId` 在不同 `conversationId` 下仍受 `UNIQUE(userId, sourceMessageId)` 约束，不得因换会话而重复入库。

### 5. 会话有效性（conversation ownership & state）
- `conversationId` 必须归属当前主体且 `state = 'active'`；不存在 → `NOT_FOUND`，已结束 → `CONFLICT`。
- 不得把新 Work 追加进已软删除（回收站）的集合，否则 `CONFLICT`。
