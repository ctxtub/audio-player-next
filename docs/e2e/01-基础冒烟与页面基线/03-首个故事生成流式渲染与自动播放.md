# 首个故事生成、流式渲染与自动播放

功能域：01-基础冒烟与页面基线

## 用户目标

访客在聊天框里发一句话，就能看着故事文字一段段流出来，写完后自动听到故事配音，故事卡上有关联的播放入口，整个过程不卡死。

## 前置条件

- 访客首次打开站点（无既有身份），停在聊天页。
- 对话接口与语音合成接口可用，浮窗配置默认开启。

## 操作步骤

1. 在输入框输入一句简短文本并发送。
2. 观察用户气泡即时出现，故事文字在流式过程中持续增长。
3. 等待生成完成，确认助手消息里出现故事卡与「播放故事」按钮，且输入框不卡在发送中状态。
4. 确认完成后 3 秒内自动开始播放（播放进度推进），悬浮播放窗出现。

## 验收标准

- 用户气泡即时出现；故事文本在流式过程中持续增长。
- 完成后助手消息含故事卡与「播放故事」按钮；输入框不卡在发送中状态。
- 完成后 3 秒内自动开始播放，播放进度持续推进；悬浮播放窗出现（配置默认开启）。
- 对话接口（流式）调用成功；语音合成接口调用成功。
- 故事完成后会话被保存，故事卡的音频链接字段为空（音频走内存播放，不落库）。

## 边界与异常

- 音频只在内存中播放、不落库；刷新页面后播放停止，行为见《硬刷新后播放停止》。
- 当上游大模型响应变慢时，流式文字增长变慢是预期现象，只要最终完成且不卡死即符合要求。
