## 用例规格

- 前置条件/夹具：`{{GUEST_FRESH}}`；已有已完成故事卡（来自 E2E-01-03）。
- 步骤：1) 双击卡片「播放故事」（≤120ms 间隔）；2) 重复 3 次。
- UI 断言：按钮终态稳定为「暂停」或「播放」之一，不闪烁；无两张卡片同时标记播放中。
- 音频/浏览器断言：`tts.synthesize` 调用数 ≤ 点击数（允许并发两路但最终只有一路在播：`audio.src` 唯一）。
- 网络/数据断言：`playback.saveProgress` 无重复异常写。
- 清理：清空会话。
- 证据要求：`ui-card-double-click.png`、`network.json`。
- 溯源：`app/services/chatFlow.ts:127`；`app/services/storyFlow.ts:73-115`（`markSessionStart`+`playAudio` 异步链存在交错窗口）。**待验证假设 H-20**：两次并发 `startStoryPlayback` 互相复位，最后一次胜出且首次会话状态被悬挂。
