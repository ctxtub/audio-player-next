# 播放中登出立即停声与状态重置

功能域：03-播放状态与内核一致性

## 用户目标

已登录用户在故事播放中途退出登录时，声音立刻停止，账号数据从界面清空，并回到登录页；不出现"已登出但声音还在响"或旧账号内容残留。

## 前置条件

- 已登录账号。
- 故事正在播放中。

## 操作步骤

1. 进入设置页（`/setting`），点击"退出登录"。
2. 在登出后约 0.5 秒与约 2 秒分别观察声音是否停止、界面显示什么。
3. 观察登出后的落点页面，以及配置、聊天、历史记录、播放进度四块内容是否清空。

## 验收标准

- 登出后页面跳转到登录页（`/auth`）。
- 登出后 0.5 秒内音频实际停止（`audio.paused=true`）；以下不一致不允许出现：登出后仍有声音可闻。
- 四块账号数据（配置、聊天、历史记录、播放进度）的界面显示全部清空。
- 登录态与访客态标识均被清除；登出后不出现残留的未授权请求。

## 边界与异常

- 登出即重置全部播放状态；再次进入需重新开始播放，不存在"登出前断点"。
- 登出后的数据隔离细节见《登出→双 cookie 清理与数据清空》。
