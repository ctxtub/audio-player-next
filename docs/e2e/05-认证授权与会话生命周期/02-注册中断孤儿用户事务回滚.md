## 用例规格

- 前置条件/夹具：AUT-NODE `createCaller` 直连 `auth.register`；mock 注入迁移第二步失败（`MOCK_FAIL_MIGRATE_STEP=1`）。
- 步骤：1) 以 `{{GUEST_FRESH}}` cookie 触发注册；2) 迁移中途失败；3) 读取 `User` 表；4) 重试注册成功。
- UI 断言：失败时注册表单报错、停留 `/auth`；重试成功后正常进入。
- 音频/浏览器断言：不适用。
- 网络/数据断言：核心断言——失败后 `User` 表**无**该用户名残留（回滚删除孤儿用户，`:89-94`）；访客数据未被部分迁移（无半复制态）；重试可成功。
- 清理：删账号与访客行。
- 证据要求：`db.txt`（失败后 User 表查询为空）、caller 错误记录。
- 溯源：`lib/trpc/routers/auth.ts:88-96`（迁移失败→回滚删除孤儿用户）；`lib/trpc/routers/auth.ts:74-76`（三步事务边界）。
- 备注：服务端回滚为已核对语义；UI 面失败提示由 E2E-05-10 覆盖。
