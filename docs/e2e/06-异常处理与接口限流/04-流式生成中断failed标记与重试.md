# 流式生成中断标记失败与重试

功能域：06-异常处理与接口限流

## 用户目标

故事流式生成中途断开时，消息明确标为失败并给出重试入口：不残留半截文本当终态，重试一次即得到完整回复，且失败不污染已保存的数据。

## 前置条件

- 访客首次打开站点。
- 下一次流式生成会在中途断开。

## 操作步骤

1. 输入并提交生成。
2. 等待断流，观察失败标记。
3. 点击重试，等待成功完成。
4. 对照服务端保存的会话快照。

## 验收标准

- 用户消息标记失败并带重试入口；助手占位收口为失败态（不残留半截文本作为终态）。
- 重试后只新增一条完整回复，旧失败占位不残留。
- 失败不触发自动播放；重试成功后的自动播放恰一次。
- 流连接已中止；会话快照与界面一致；重试请求的上下文不含失败消息（过滤语义见《失败消息重试上下文正确性》）。

## 边界与异常

- 快照保存失败行的取舍以界面一致为准：界面显示失败标记，快照即不得把半截助手文本当终态保存。
