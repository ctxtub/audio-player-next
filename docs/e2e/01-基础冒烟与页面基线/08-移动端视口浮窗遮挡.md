# 移动端视口下浮窗不遮挡操作

功能域：01-基础冒烟与页面基线

## 用户目标

用手机小屏听故事的用户，悬浮播放窗不能挡住聊天输入框和主要操作；关掉浮窗开关后它立刻消失，但故事照常播。

## 前置条件

- 窄屏手机视口（如 390×844）。
- 站点处于播放中状态，悬浮播放窗可见。
- 用户停在聊天页。

## 操作步骤

1. 在 `/chat` 滚动到底部。
2. 检查悬浮播放窗与输入框、底部 TabBar 是否重叠，确认输入框与主操作可用。
3. 关闭浮窗开关，确认浮窗立即消失，且播放不受影响。

## 验收标准

- 悬浮播放窗不遮挡输入框与主操作。
- 关闭浮窗开关后浮窗立即消失。
- 关闭浮窗不影响播放（播放进度持续推进）。
- 开关浮窗不触发新的网络请求。

## 边界与异常

- 关闭浮窗只是隐藏悬浮入口，不停止播放、不改变播放状态。
- 浮窗的显隐完全跟随开关：开则显示，关则立即隐藏。
