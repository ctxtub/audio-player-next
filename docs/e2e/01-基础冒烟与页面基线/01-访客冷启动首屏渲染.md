## 用例规格

- 前置条件/夹具：`{{GUEST_FRESH}}`（清 cookie）；`{{E2E_PORT}}` 服务健康。
- 步骤：1) 打开 `/` → 期望重定向 `/chat`；2) 记录首屏快照；3) 刷新一次。
- UI 断言：聊天空态文案、输入框、底部 TabBar、HeaderArea 建议项渲染；无 JS 错误横幅。
- 音频/浏览器断言：`document.querySelector('audio')` 存在（(main) 布局常驻）；`paused=true`；console 零未捕获异常。
- 网络/数据断言：`config.get`、`auth.profile`（或等价 profile 调用）返回成功；`GuestConfig`/`GuestChatMessage` 无新增脏行。
- 清理：清 cookie/storage；`GuestConfig` 中本用例 `g_` 行可保留（隔离库）。
- 证据要求：`ui-first-load.png`、`console.json`、`network.json`。
- 溯源：`app/(main)/layout.tsx:17-27`；`app/(main)/chat/components/OnboardingModal/index.tsx:48,56`（首访 onboarding 仅一次）。
