## 用例规格

- 前置条件/夹具：无 cookie HTTP 客户端；`{{E2E_PORT}}` 健身。
- 步骤：1) 直连 `agent.interact`、`tts.synthesize`、`playback.saveProgress`、`chat.saveConversation`（均无 cookie）；2) 直连 `auth.login`（错误凭证）；3) 直连 `auth.profile`（无 cookie）；4) 携带伪造 `guest=1` 旧式 cookie 调用受保护接口。
- UI 断言：不适用（API 面）；联动 UI：sessionGuard 不因本矩阵的 401 触发误登出（有登录态的旁路上下文不受影响）。
- 音频/浏览器断言：不适用。
- 网络/数据断言：核心断言——步骤 1 全部 `UNAUTHORIZED`（401）；步骤 2 返回登录错误而非 401 会话失效语义（不触发前端登出闭环）；步骤 4 旧式 `guest=1` 不被接受（需 `g_<uuid>` 形态的有效访客 cookie）；`auth.*` 调用不产生意外 Set-Cookie 清理。
- 清理：无（无状态）。
- 证据要求：`network.json`（状态码矩阵）。
- 溯源：`lib/trpc/init.ts:45,54-56`（`guardedProcedure` 无有效 cookie → `UNAUTHORIZED`「请先登录或以访客身份访问」）；`lib/trpc/client.ts:24-36`（非 `auth.*` 401 才触发 sessionGuard）；`lib/client/sessionGuard.ts:18-24`（访客/匿名 401 不走登出闭环）；`lib/trpc/routers/auth.ts:149-168`（`g_` 前缀访客 cookie 形态）。
- 备注：与 E2E-01-06（页面路由矩阵）拼成完整鉴权矩阵：页面层 middleware，API 层 guardedProcedure。
