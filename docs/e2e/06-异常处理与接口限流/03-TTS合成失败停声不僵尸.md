# 语音合成失败时停声不残留

功能域：06-异常处理与接口限流

## 用户目标

语音合成失败时，播放界面干净地回到可再播状态：没有"显示在播、实际无声"的假态，没有残留的进行中浮窗，用户点一次重试就能继续听。

## 前置条件

- 访客首次打开站点，已有一张可播放的故事卡。
- 语音合成服务下一次返回失败。

## 操作步骤

1. 点击故事卡「播放故事」（首次合成即失败），观察按钮、提示与音频状态。
2. 变体：播放中让下一段合成失败（预载完成后触发播放的位置），同样观察三处状态。

## 验收标准

- 失败后按钮回到可再播状态；无"正在播放"假态残留。
- 出现一次"语音生成稍有延迟"或等价提示。
- 音频处于暂停态；播放器未被赋值为失败响应；浮窗不显示进行中。
- 失败后无重试风暴（单次失败，或既有重试链耗尽即止）。
- 播放进度不因失败回写错误的段落；会话快照不含失败音频引用。
