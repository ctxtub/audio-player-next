# 创作卡范围纠正

用户明确指出，创作卡减少内容、在首页设置播放时长均不符合预期。本次恢复原有展示边界，取代 2026-10-11 修复文档中“创作页直接启停和调整时长”的扩展规则；历史文档保留原始记录。

- 创作页仅展示原有集名、连续创作状态、自动播放时长与剩余预算，保留耗尽后的重置和前往设置。启停与时长配置回到设置页，不提供首页开关、滑块或新增说明。
- 正文、原有故事预览长度、播放状态和查看全文入口保持原契约。修复布局不得通过隐藏文字、删内容或缩短预览达标。
- 只调整相关展示及既有创作旅程，不扩展其它入口、恢复流程或业务契约。由当前助手直接修改。
- 执行 test:fast、隔离 production build、diff-check 和受影响创作旅程。内置浏览器用正常长度的合成故事复验预览与全文，不能用一句 mock 回复代表故事卡内容密度。
