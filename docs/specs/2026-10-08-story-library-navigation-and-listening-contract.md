# 故事库导航、续听与来源创作契约

本次实现契约；交付验证记录见本地 `.e2e-results/`。它补充既有创作与单轨播放规则，明确改变跨篇默认从头播放与历史集不能恢复编辑的行为。

## 资源与路径

- 正常集合列表为 `/library`；收藏 `/library/favorites`、回收站 `/library/trash`，以 `type=works` 选择单篇范围，默认故事集。搜索为 `q`。
- 集详情 `/library/collections/:collectionId`；集内正文 `/library/collections/:collectionId/works/:workId`。正文读取必须验证 Subject、父集可用性和父子匹配。
- `/library/works/:workId` 为无归属正文及只读解析入口；旧 `/library/:workId` 解析到正式地址。已有归属的作品统一使用嵌套正文地址。
- 来源记录 `/chat/conversations/:conversationId`，只读取目标，不改变 active；当前编辑入口仍为 `/chat`。旧 view 查询参数归一到收藏/回收站路径；`/player` 继续进入故事库。
- 浏览、正文、来源记录与播放器内容导航不切曲或自动生成。主布局继续持有唯一音频宿主。返回父集/库保留最近列表条件，列表滚动在本次登录内恢复；播放器回集可通过 `focusWork` 定位当前篇。

## 创作与回听闭环

创作集名可进入所属集；正式故事卡的全文使用统一正文，未保存草稿继续用局部阅读。播放器可查看正文、所属故事集和来源记录。集合/正文/播放器显示同一正式 Work 的状态，改名更新集合、正文、创作集名与播放标题，不重建播放会话。

查看旧记录不会续写。显式“续写这个故事集”使用原子恢复接口：验证归属及集合可用性、匹配客户端已知 active、关闭旧 active 并激活目标，User/Guest 对称。数据和已保存成员保留；closed 表示非当前编辑而非永久结束。

切换前保存已完结消息；有未保存输入时显示明确的切换选择，输入按会话驻留本次登录内存，并提供返回上一份创作入口。当前手动生成未完成时要求等其完成再切换，避免丢失未保存正文。远端失败不清空当前编辑。目标消息取得后才切换，并作废旧 promotion/快照代次；服务端拒绝 closed 会话的迟到快照写入。恢复旧集默认关闭自动创作，用户提交才生成下一篇。

新建按钮为“新建故事集”，继续执行既有强重置：停声、取消旧自动任务，保留已保存故事与旧会话。仅未保存输入/消息需要确认，确认使用应用内可访问对话框；无风险新建直接完成。

## 播放与进度

单篇列表/详情投影读取正式 StoryAudioAsset 和毫秒进度。未知时长不伪造；历史 completedAt 不覆盖本轮重播位置。

同篇播放中点击暂停，暂停点击继续，完播点击重播。切到另一篇默认恢复该篇合法断点，已到末尾则从头；明确“从头播放”才重置。切换前强制保存旧进度。异步音频返回必须仍属于发起 session，不能污染新目标的恢复位置。

整集回听只引用已保存 workId 的顺序快照，不触发 AI。入口有继续听和从头听；播放器显示集内列表、上一篇/下一篇与关闭连播。下一篇按快照顺序从头开始，交接前验证有效成员；删去待播篇会被跳过；到集尾停止。刷新恢复单篇暂停，不隐式恢复连播。失败可重试当前目标或跳过，不静默生成内容。

回听与连续创作互斥。显式起播另一故事取消旧自动创作任务；重新开启创作开关退出回听队列。纯浏览不取消任务。预算与预生成只使用当前编辑上下文对应的音频，不能由其他故事集的声音触发。手动目标优先于迟到的保存/TTS/自动交接。

睡眠定时在整集交接前设置到下一会话，并携带剩余实际收听预算；当前故事结束模式不续播。定时到期取消回听及自动创作的交接权，新建/登出作废旧任务。

## 管理与删除

单篇和集合收藏独立；收藏与回收站可切换范围。集内标题进入正文，更多操作提供改名、收藏、从头播放及回收站。

正常成员、篇数、搜索、续听目标统一排除删除篇；空集保留。整集软删写入集合 deletionBatch 与成员 collectionDeletionBatch，同一事务完成。恢复整集只恢复该批次，单独删除篇保留；旧数据删除来源不明时保守保留成员删除状态，可在单篇回收站显式恢复。父集仍在回收站时不能单独恢复成员，条件写也校验父集状态以覆盖竞态。

删除当前故事/所在集先保存可保存的进度，再停声、清除正式播放身份和自动任务；Undo 只恢复内容，不自动起播。删除其他队列成员不打断当前故事。永久删除沿用现有音频感知事务与二次确认。

## 验证与边界

开发窄测：`node tests/server/story-library-lifecycle.mjs`，每次创建独占临时 SQLite，覆盖 User/Guest 删除来源、可见性、归属、active 冲突与 closed 写入拒绝。完成门：`yarn test:fast`、隔离环境的 `yarn build` 与 `git diff --check`。

交付最后阶段复用创作、重置、连续生成和跨页播放旅程，补充“整理故事并回到原集续写和收听”。全部从 production build 的可见 UI 操作，不调用 Store、业务 API 或预造内容。

本次不提供跨集移动、手工合并/拆分、自由排序、正文编辑或新分支。大规模集合分页、更多排序/筛选与跨设备队列需后续按使用规模设计；不将本地队列写入持久化。
