# 三处播放镜像状态一致

功能域：01-基础冒烟与页面基线

## 用户目标

故事播起来之后，不管用户在聊天页、播放器页还是设置页之间来回切换，看到的播放状态都是一致的（播就是播、停就是停），声音不中断、不重头来，浮窗也一直在。

## 前置条件

- 站点已进入播放中状态（生成一个短故事并开始播放，或由服务端预置一段可播放内容）。
- 对话接口与语音合成接口可用。

## 操作步骤

1. 在 `/chat` 开始播放，读取悬浮播放窗与故事卡的播放状态。
2. 经客户端路由切换到 `/player`，读取全屏播放器的大按钮、进度条与段落徽标。
3. 经客户端路由切换到 `/setting`，确认悬浮播放窗常驻且状态与播放中一致。
4. 经客户端路由回到 `/chat`，再读一次播放时间，确认进度在前进。

## 验收标准

- `/chat`：悬浮播放窗优先正确渲染倒计时标签（如 `29:xx`）与暂停图标；故事卡播放按钮处于「暂停播放」态（段落徽标只在全屏播放器呈现，浮窗不做要求）。
- `/player`：全屏大播放器按钮显示暂停态；段落指示徽标正常渲染（如 `第 1 / 4 段`）。
- `/setting`：悬浮播放窗常驻挂载，暂停键状态与播放中一致。
- 跨路由切换（`/chat` → `/player` → `/setting` → `/chat`）期间声音不中断、不重置、不卡死，播放进度单调递增。
- 路由切换过程中不发起新的语音合成或对话请求（复用既有音轨与会话）。

## 边界与异常

- 悬浮播放窗与全屏播放器展示的信息粒度不同（浮窗以倒计时为主，全屏含段落徽标），属预期差异。
- 本场景只覆盖客户端路由切换；硬刷新会停止播放，行为见《硬刷新后播放停止》。
