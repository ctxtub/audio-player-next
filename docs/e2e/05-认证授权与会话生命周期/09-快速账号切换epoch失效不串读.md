# 快速切换账号不串读

功能域：05-认证授权与会话生命周期

## 用户目标

从账号 A 快速切到账号 B 时，最终只看到 B 的数据：A 还在路上没回来的数据不得晚到覆盖，不出现两家数据拼在一起的一帧。

## 前置条件

- 账号 A 与账号 B 均有可区分的数据（不同的聊天文本、不同的配置值）。
- 账号数据加载较慢（使"在途"窗口可被观测）。

## 操作步骤

1. 登录账号 A。
2. 在 A 的数据还在加载时登出并立即登录账号 B（间隔极短）。
3. 静置几秒后读取聊天、配置、历史、进度四处数据。
4. 重复多次切换，确认终态稳定。

## 验收标准

- 终态只显示账号 B 的数据；A 的在途响应不得晚到覆盖（旧代次结果丢弃）。
- 不出现 A、B 混合渲染的中间帧。
- 切换后无 A 的残留音频与浮窗状态。
- A 的在途保存不写入 B 名下（无交叉写入）。

## 边界与异常

- 账号代次（每次登录递增）：各数据存储以代次捕获与校验，旧代次的结果一律丢弃。
