# 移动端悬浮播放器与半屏详情

## 目标与方案

移动端以对话创作为主，播放入口不再占据整行底部布局。小胶囊靠右悬浮，点击标题打开底部半屏详情；暂停按钮独立操作。复用全局 Mini、Expanded、播放会话与唯一音频宿主。

- 小于 768px 使用 `compact-floating`，不受桌面悬浮偏好影响；不提供拖动，避免与页面滚动竞争。
- 胶囊宽度 232px，最小高度 64px，保留短标题、状态、粗进度和独立播放按钮；长标题省略，展开按钮无障碍名称保留完整标题。
- 创作页按输入栏实际外框高度避让，包括多行输入与底部导航安全区；播放入口不再抬高输入栏。其他页面停在导航上方，并为列表末项提供滚动避让。
- 软键盘展开时隐藏手机胶囊，键盘收起后恢复；展开详情时隐藏胶囊。隐藏、展开、收起、页面导航均不改变播放。
- 手机详情默认高度为 60dvh，并限制在可视屏幕内；隐藏装饰封面以优先展示标题、时间轴与播放控制。倍速、定时、正文与故事集操作保留在可滚动面板内。
- 桌面保留可拖悬浮/固定两种模式；打开详情仍为右侧面板。

## 实施计划

1. 更新布局派生与底部占位：手机悬浮不产生 docked 占位；输入栏通过 ResizeObserver 发布实际高度，卸载时清理。
2. 调整移动胶囊、半屏尺寸与内容密度，同步设计规范及设置说明。
3. 复用集合详情起播跨页播放旅程，增加移动端输入避让、独立暂停、半屏展开、收起继续播放和尺寸切换验收。
4. 执行 `yarn test:fast`、隔离环境的 `yarn build`、`git diff --check`，最后运行受影响的 production 浏览器旅程并检查截图。

## 验收标准

- 375px、430px 手机上胶囊非整行，输入框和发送按钮可见且不被遮挡；多行输入后仍避让。
- 点击胶囊标题展开约 60% 屏高的底部面板，核心播放控制无需滚动即可触达；完整标题仍可通过可访问名称识别。
- 胶囊暂停按钮不打开详情；展开、关闭按钮、遮罩与顶部下滑收起均不改变播放进度或暂停状态。
- 播放中跨创作/故事库导航保留同一会话；列表末项可滚动到胶囊上方；手机/桌面切换不残留手机尺寸或桌面拖拽坐标。
- 键盘抑制沿用既有检测；真实手机软键盘行为若无法在本地自动化证明，登记 MANUAL。

## 范围与风险

只调整 UI 布局、展示契约与已有浏览器旅程；不改变 API、持久化结构或播放状态机。小屏横屏和大字号可滚动，真实移动设备的软键盘与触摸手势需要人工确认。原始证据保存在私有目录，不入 Git。
