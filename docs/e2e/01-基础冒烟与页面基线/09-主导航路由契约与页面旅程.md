# 主导航路由契约与页面旅程

功能域：01-基础冒烟与页面基线

## 用户目标

用户在站点内通过主导航栏（TabBar）或浏览器前进后退，能够在创作（`/chat`）、故事库（`/library`）、故事详情（`/library/[id]`）、设置（`/setting`）以及兼容播放器（`/player`）页面之间无缝切换；全局播放控制器（`AudioControllerHost`）在主布局路由切换中生命周期保持连续；根路径正确重定向至创作页；旧版播放器保持兼容边界且导航状态指示正确。

## 前置条件

- 服务可用，配置与身份接口正常。
- 访客或已登录身份正常可用。
- 显式预置或关闭新手引导（本地标记 `chat_onboarding_seen_v1`），确保测试前置确定性。

## 操作步骤

1. 打开站点根路径 `/`，确认自动重定向进入聊天页 `/chat`。
2. 观察底部主导航栏：创作 Tab 处于选中态（`aria-selected="true"`），故事库与设置 Tab 处于未选中态。
3. 检查全局布局：确认常驻音频控制器（AudioControllerHost）挂载正常，记录宿主活动代理标记。
4. 点击主导航栏「故事库」Tab，观察页面切换至 `/library`：故事库骨架（Story Library）正确呈现，故事库 Tab 变为选中态，且全局音频控制器宿主生命周期与状态保持连续未被销毁。
5. 在主导航栏点击「设置」Tab，观察页面切换至 `/setting`：设置页面呈现，设置 Tab 变为选中态，全局音频控制器宿主生命周期与状态持续保持。
6. 点击浏览器后退（Browser Back），观察页面回到 `/library`，故事库 Tab 保持选中态，故事库骨架正常呈现。
7. 访问合法正整数 ID 的故事详情页 `/library/1`，观察故事详情骨架呈现，故事库 Tab 保持选中态。
8. 点击浏览器后退（Browser Back），观察页面回到 `/library`，故事库 Tab 保持选中态。
9. 直接访问 `/player` 进入兼容播放器页面：确认页面 URL 保持 `/player` 无重定向，旧版播放器核心地标正常渲染，主导航故事库 Tab 呈现选中态（compatibility active alias）。
10. 在 `/player` 页面点击主导航「故事库」Tab，观察正确导航至 `/library`，故事库骨架呈现。
11. 点击浏览器后退，确认正确回到 `/player`，旧版播放器与故事库 Tab 选中态恢复。

## 验收标准

- 打开 `/` 必须自动重定向至 `/chat`。
- 访问 `/library` 时，故事库 Tab 处于选中态（`aria-selected="true"`），故事库 Shell 正常显示。
- 访问 `/library/[id]`（合法正整数 ID）时，故事库 Tab 保持选中态，故事详情 Shell 正常显示。
- 直接访问 `/player` 时保持 `/player` 路径且无重定向，旧版播放器地标正常显示，故事库 Tab 处于选中态。
- 在 `/player` 页面点击故事库 Tab 能正确导航至 `/library`。
- 浏览器前进后退（Browser Back）行为在所有路由跳转间符合预期。
- `/chat`、`/library`、`/setting` 处于同一 Main Layout 生命周期，`AudioControllerHost` 在路由切换过程中不被移出或重建。
- 全程无未捕获异常与控制台报错。

## 边界与异常

- 故事详情页合法 ID 仅限正整数，非法 ID 返回 404（由单元测试与骨架守卫保障）。
- `/player` 为冻结兼容边界，保留旧版播放器能力，不自动迁移至 `/library`。
- `/chat` 首访引导面板（OnboardingModal）由本地标记 `chat_onboarding_seen_v1` 判定，测试前置显式处理，不得依赖偶发首访状态。
