# 连续创作默认开启与自动下一作品

功能域：10-会话与作品集连续创作

## 用户目标

进入创作页后连续创作默认开启；当前作品整轨播完后，若下一个作品已就绪则自动无缝续播，不打断用户，也不需要手动点播。

## 范围与边界声明

本场景覆盖 T2「创作页、新建创作与连续创作」的默认开启、lookahead=1、调度窗与自动续播（L1 + L3）。
**明确排除**：T1 集合 CRUD、T3 单轨音频资产与 30 天缓存、T4 Library UI 与 contract migration。

## 契约验收标准

### 1. 默认开启（default enabled）
- 新会话初始化后连续创作开关默认 `enabled`，无需用户操作。
- 开关状态与 `continuousCreationStore.status` 一致；关闭后不再调度。

### 2. 预算快照（budget snapshot）
- 新会话预算 `budgetMs` 等于设置页播放时长快照（`defaultSleepTimerMinutes`，分钟转毫秒），在会话/新建创作时单次捕获。
- 预算变化不回溯已开始的会话；必须经新建创作重新快照。

### 3. lookahead=1 与调度窗（single next job, 30–120s window）
- 同时最多存在一个 next job（`generating_next` / `preparing_audio` / `next_ready` 之一），重复调度为 no-op。
- 进入窗口条件：`enabled` ∧ 预算有效 ∧ 当前 track 正在播放 ∧ 无 next job ∧ epoch 匹配。
- 窗口 = 下一作品准备耗时移动平均，clamp 到 30–120 秒；冷启动固定 60 秒。

### 4. 自动下一作品（auto next work）
- 当前 track `ended` 且 next 就绪 → 自动播下一 Work，不进入 `waiting_next`。
- 当前 track `ended` 且 next 未就绪 → 进入 `waiting_next`，**不扣预算**；就绪后自动续播。
- 播完集合最后一个 Work 且无更多内容 → `ended`，不再生成。

### 5. 不扣预算的时机（no budget burn）
- 生成、TTS、缓冲（stalled/waiting）与暂停期间预算不递减。
- 仅 `reportAudioActive(true)`（音频实际推进）期间递减。
