# 断点恢复与段落切换中合成失败的可重试边界

功能域：06-异常处理与接口限流

## 用户目标

从断点恢复播放时若语音合成失败，浮窗停在可重试的断点态：进度不丢，故障解除后点一次就从断住的段落继续播。

## 前置条件

- 访客身份保留；服务端预置一条播放进度（下一段为第 3 段，共 4 段）。
- 下一次语音合成返回失败。

## 操作步骤

1. 刷新进入断点就绪态。
2. 点击播放（本次合成失败），观察浮窗与音频状态。
3. 故障解除后再次点击播放。

## 验收标准

- 失败后浮窗保持"断点就绪/第 3/4 段"或等价可重试态；故障解除后重试成功且段落正确衔接。
- 失败时音频处于暂停态；重试成功后从第 3 段起播。
- 进度查询命中预置行；重试以同一段文本再次合成；失败路径不删除进度行（可恢复）。

## 子场景 B · 段落切换中合成失败

- 覆盖自然播放到段尾、经段落收尾自动切下一段时的合成失败（主场景覆盖"断点恢复点击"路径）。
- 前置：不预置断点，自然播放第 2 段至段尾；段尾前合成服务保持失败。
- 步骤：播放至段尾自动切换 → 切换合成失败 → 观察浮窗与音频 → 故障解除后手动重试。
- 验收：浮窗保持可重试态（不跳段、不增殖卡片）；音频暂停；进度行停在切换前索引（未删除、可恢复）；终态失败提示恰一次；故障解除后重试衔接下一段。

## 子场景 C · 合成缓慢时暂停意图不被覆盖

- 把"断点恢复点击 → 合成返回"的窗口放大到约 3 秒，检验等待窗口内的暂停意图不被合成返回覆盖（暂停意图口径关联《段落切换窗口内暂停不续播》）。
- 前置：预置进度（下一段为第 3 段）；合成返回延迟约 3 秒。
- 步骤：刷新进入断点就绪 → 点击播放 → 合成返回前点暂停 → 合成返回后观察终态 → 延迟解除后从断点段正常起播。
- 验收：窗口内暂停后终态保持暂停，不自动续播；合成返回不覆盖暂停意图；延迟解除后从第 3 段起播。

## 提示语义

- 段落切换快速失败时，过程性提示可被后续终态失败提示替换（提示组件为单容器、无队列，后一次展示为准）；终态失败提示优先。
- 过程提示不构成成功或失败的证据；成功与失败只以本场景的验收为准（浮窗可重试态、音频暂停、进度行保留、同段重试），不得以过程提示是否可见判定。
- 只有等待通常超过约 500–800ms 且需要防重复点击或解释等待时，才考虑播放器局部加载状态；本次暂不做该界面改造。
- 两个失败提示点的竞态以后一次展示为准。

## 边界与异常

- 三个子场景的失败都不删除进度行：任何时候都有可恢复的断点。
