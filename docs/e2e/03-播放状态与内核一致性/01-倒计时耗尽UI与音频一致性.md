## 用例规格

- 前置条件/夹具：`{{GUEST_FRESH}}`；seed 访客进度行（`nextParagraphIndex=0`、`remainingAllowedMs=3000`）指向 `{{E2E_STORY_4P}}`。
- 步骤：1) 冷启动进入 `/player`（断点就绪）；2) 点击播放；3) 在 t+2s/3.5s/5s 三个时点采样 UI 与音频状态。
- UI 断言：预算耗尽后按钮回到「播放」图标、倒计时隐藏；若同时音频仍在响，记为声画分歧（本用例核心）。
- 音频/浏览器断言：`audio.paused=false` 且 `currentTime` 递增 vs UI 已显示暂停——两者不一致即为缺陷证据；段落在播完自然结束前不得中断。
- 网络/数据断言：耗尽期间不再触发预载（`agent.interact` 不新增，与「仅播放态触发预载」一致）。
- 清理：清进度行、清 cookie。
- 证据要求：`audio.json`（三时点采样）、`ui-expiry-*.png`。
- 溯源：`stores/playbackStore.ts:189-216`（tick 在 `remainingMs=0` 时仅置 `isPlaying:false`，:204-209 未暂停音频元素）；`components/AudioControllerHost/index.tsx`（无对 store 暂停的订阅）。
