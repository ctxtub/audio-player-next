# 全前端页面与状态一致性

用户要求全量 review 前端页面及状态，并完成一致性修复；起因是故事卡继续播放与查看全文尺寸不一致。由主助手直接完成，不使用子代理，不增加业务内容。

## 页面与状态清单

- 认证：登录、注册、必填/格式验证、请求中、认证错误、会话失效、访客与首次引导。
- 创作：首页空态、建议、输入/禁用/发送中、普通文本/引导/故事草稿、保存/生成/语音准备、保存或播放失败与重试；故事保存、播放、暂停、完成；新建取消/确认、旧草稿返回。
- 创作记录：读取、完整记录、读取失败/不可用、返回、恢复创作、切换确认、恢复错误。
- 故事库：全部/收藏/回收站/搜索空态与有内容、加载、加载失败与重试、末页、收藏、更多、回收与撤销、恢复、永久删除确认/取消/进行中。
- 集合：加载、错误、不可用、标题和全部操作、整集起播/续播、集内故事播放/暂停/准备、更多管理、续写与切换。
- 单篇：加载、错误、不可用、正文/摘要/提示词、重命名编辑/错误/忙碌、收藏、回收、播放准备/播放/暂停/结束/失败。
- 设置：访客/登录用户/同步中、主题亮/暗/系统、连续开关与时长、语速、浮动开关、音色选择/试听中/失败。
- 全局：导航选中、Mini docked/floating、展开播放、进度/速度/睡眠菜单及自定义输入、关闭/焦点/窄屏滚动、提示/撤销与禁用。
- `/`、`/player`、`/library/favorites`、`/library/trash`、单篇旧 URL 属兼容入口，检查重定向/视图结果，不重复建设页面。已不可达旧组件只做来源审查，不冒充实际产品状态。

## 统一契约

- 摘要全文热区同时支持点击、Enter 与 Space，焦点可见；预览及全文内容不变。
- 指引卡片跟随主题，正文保真；使用中文业务标题，不展示没有对应流程的等待确认或终端状态装饰。
- 同组操作等高、同字号/行高/圆角/内边距；故事卡主次按钮还需等宽。使用共享 Sass 规则，避免逐处尺寸漂移。
- 普通文字操作最小触控高度 44px；圆形播放器主按钮保留更大尺寸，图标操作最小 44px。主操作纯蓝、次操作中性/描边、危险操作红色；禁用、焦点、loading 规则统一。
- 播放器语速与定时菜单在可滚动面板内展开，所有选项及自定义字段必须可达，不被祖先 overflow 裁掉；保留 Escape 与焦点恢复。
- 弹层操作与表单使用同一尺寸和间距；输入可伸缩、长文案可换行；选择项/导航保持各自语义，不强行变成普通按钮。
- 失败消息在亮暗主题下保持正文对比度；搜索框清除操作不得遮挡输入；技术性网络/上游错误显示对应的中文重试反馈，保留原产品中文错误。
- 加载/空态/不可用/错误保持一致的容器和返回/重试操作；错误内容不能溢出，恢复入口不得退化为浏览器原生按钮。
- 失败对话只在当前可重试消息上提供重试入口，不显示无效的历史/同轮重复重试按钮；保存失败的主操作与健康故事卡保持同一顺序。
- 不缩短卡片内容、预览或正文，不新增配置入口；新建入口和既有草稿保护/鉴权/持久化/播放状态机不变。
- 手机多轮对话滚动到底时，末条故事操作必须完整滚动至 Mini 上方；滚动区按 compact Mini 的共享高度 token 留出空间，不抬高输入栏。
- 320px 窄屏下，主题选项网格和单篇操作栏不得横向溢出；保留完整标签并允许操作栏换行。已收藏状态沿用故事库的琥珀色语义。

## 验证

逐页逐状态记录源码审查与实际浏览器证据，手机/桌面、亮/暗、窄屏与关键错误/弹层至少实际验证。短暂或不可达状态如实注明，不声称图片覆盖所有组合。错误/延迟只能来自隔离外部网络/upstream mock，不注入 Store 或生产测试开关。运行 test:fast、隔离 production build、diff-check，复用现有完整旅程；最后通过内置浏览器验证最终构建的操作几何、视觉与动线。证据保存在 ignored 目录，验收后本地提交。
