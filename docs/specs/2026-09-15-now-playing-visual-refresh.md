# Now Playing 视觉一致性刷新

状态：IMPLEMENTED（待独立验收）

## 目标

- 统一桌面浮动播放器、桌面展开面板与移动端底部播放器的视觉语言。
- 强化标题、播放状态、进度和主操作的层级，消除浏览器原生按钮观感。
- 保持现有 Session、Transport、路由、焦点与手势语义不变。

## 设计决策

- 使用现有 Liquid Glass token，增加播放器专用尺寸 token，不在组件样式中散落尺寸常量。
- Expanded 使用一致的“氛围封面 → 时间轴 → 播放控制 → 辅助工具 → 内容动作”顺序。
- PC 仍为右侧面板，移动端仍为底部 Sheet；两端仅容器和密度不同，组件语言一致。
- Mini 使用同一渐变封面标识和强调色播放键；桌面浮窗避开页面主输入区的视觉竞争。

## 验收标准

- 1440×900 与 390×844 下均无溢出、控件重叠或原生按钮样式。
- 所有可交互控件保留至少 `--size-touch-target` 命中区和清晰 focus-visible。
- 展开、关闭、播放、暂停、seek、倍速、定时和正文入口行为不变。
- 通过相关 Now Playing 单测、catalog、lint、tsc、build 与浏览器测试。
