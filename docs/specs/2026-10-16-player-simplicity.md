# 播放器信息与操作精简

依据用户对重复状态、按钮和动线的反馈，调整播放器与故事集的展示层；不改变自动播放、连续创作、存储或音频控制规则。

## 展示规则

- 常规播放、暂停和完成由主按钮、进度和选中样式表达，不额外重复“已暂停”“正在播放”“播放完成”或“关闭后播放继续”。保留按钮的无障碍名称。
- 准备语音、恢复进度、播放失败等无法从进度推断的信息必须明确显示，失败时保留重试入口。
- 迷你播放器副标题优先完整利用空间展示作品名；与主标题相同则省略。仅准备中、错误保留状态前缀。
- 播放主区固定保留后退五秒、播放/暂停、前进五秒。播放设置中按需提供“从头播放”；尚未推进时隐藏，已播完由主按钮重播，不再同时显示第二个重播按钮。五秒操作在图标中明确标注数字，避免误认为切篇。
- 手机底部导航使用“正在听 / 播放设置 / 选集”，视觉区别于播放动作按钮。切换导航不改变声音。
- 选集以可点击的列表作为切篇入口，删除重复的上一篇/下一篇按钮与例行状态徽标。选择后返回播放控制；失败时保留错误提示及重试入口。
- 故事集与创作记录导航移到选集列表之后，以轻量入口展示；保留完整功能、触控尺寸与键盘可访问性。
- 故事集成员行已具有播放按钮、进度和当前项高亮，不重复显示播放状态徽标。

## 验证

复用故事集跨页播放旅程，检查暂停/继续、前后五秒、完成后单一重播入口、选集切换、返回正文/故事集/创作记录，以及 375×667、430 像素与桌面布局。使用独立数据库、本地模拟上游的 production build，仅通过可见 UI 操作。保留准备中与失败的信息反馈，完成静态检查、生产构建和 diff 检查。
