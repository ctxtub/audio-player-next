# 运行时卫生与高频请求保护

## 目标

在不改变故事创作、播放和作品集用户行为的前提下，收敛本地交付环境的磁盘与进程泄漏，并为可取消的外部请求和高频播放进度写入补齐资源保护。

## 行为契约

- 浏览器交付快照只保留当前提交及最近两个可淘汰的已完成快照；正在使用、正在构建、未完成或非 SHA 目录不得被误删，运行结束后再收敛缓存。
- 浏览器 harness 在 mock 启动后必须立即持久化回收信息；app 启动失败时必须回收 mock、端口文件和当次指针。
- 每次运行使用独占目录保存数据库、SQLite 辅助文件和合成音频；正常结束及端口选择、迁移、健康探测失败后均按所有权回收。启动前原子占有运行锁；已有指针或锁时拒绝启动，保留旧运行的回收信息。
- teardown 必须匹配本次 run-id 与锁所有权；回收失败保留未完成资源的 handle、指针和运行锁，已回收资源标记完成后再重试，不能再次操作旧 PID。
- 隔离构建与服务只继承必要系统变量，业务配置、Tracing 和外部上游全部使用合成值。
- 作品集标题生成超时后必须主动取消 OpenAI 请求；超时、上游失败和不合格输出只记录分类信息，不记录 prompt 或故事正文。
- 单轨播放进度接口增加主体维度限流，阈值必须显著高于正常客户端每 10 秒一次的写入频率，不能影响暂停、切曲和结束时的强制落盘。
- Next.js lint 与 Turbopack 配置迁移到当前受支持入口，不改变现有校验范围和 SVG 行为。

## 非目标

- 本次不删除历史分段音频表、读取路由或迁移清理链；其退役需要独立的数据兼容方案。
- 本次不拆分大型 Store 或服务文件，避免把资源治理与状态机重构混在同一变更中。
- 本次不把进程内限流器替换为分布式存储；多副本部署前另行实施。

## 验收

- `yarn lint` 使用 ESLint CLI，`yarn build` 不再出现 `next lint` 或 `experimental.turbo` 弃用警告。
- production 浏览器 harness 能启动、运行并完成回收；快照目录最终不超过三个已完成 SHA 快照。
- 标题生成保持成功标题与确定性回退语义，超时会触发 abort。
- 正常播放进度保存不受影响，异常高频请求返回 `TOO_MANY_REQUESTS`。
