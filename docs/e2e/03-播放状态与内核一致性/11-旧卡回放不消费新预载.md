## 用例规格

- 前置条件/夹具：`{{GUEST_FRESH}}`；两条故事卡（旧 A、新 B），B 已产生 ready 预载。
- 步骤：1) 让 B 播放至临近段尾（预载 ready）；2) 暂停；3) 回放旧卡 A；4) 快进至 A 临近段尾。
- UI 断言：A 结束时**不得**把 B 的预载内容当作 A 的下一段播放。
- 音频/浏览器断言：A 结束后播放停止或基于 A 的正确续写；无串台文本。
- 网络/数据断言：`isLatestMessage(A)`=false → `preload.consume` 不被调用（`preloadStore` 状态不被清）。
- 清理：清空会话、清进度。
- 证据要求：`network.json`、`console.json`。
- 溯源：`stores/chatStore.ts:584-593`（仅最新故事卡视为最新）；`components/AudioControllerHost/index.tsx:296-306`（预载消费门控）；`stores/preloadStore.ts:155-166`（`consume`）。**待验证假设 H-09**：门控语义边界。
