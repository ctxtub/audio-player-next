# 主题配置一次性水合与双写保留

功能域：04-云端存储与多端数据调和

## 用户目标

用户设置的主题在首次打开时一次生效，之后切换页面不闪烁、不被改写；退出登录后主题保持不变，仍是用户选的样子。

水合指首次加载时把云端配置一次性合入本地；双写指主题在本地与云端各存一份，登出时本地一份不清。

## 前置条件

- 全新访客身份。
- 本地存的主题与云端存的主题不同（制造分歧起点）。
- 账号 A 可用。

## 操作步骤

1. 首次加载，记录主题的生效来源（本地还是云端配置）。
2. 登录账号 A，观察主题是否被云配置改写。
3. 登出后以访客身份重新进入，读取主题。
4. 在应用内多次切换页面（客户端路由），观察主题是否重复加载或闪烁。

## 验收标准

- 主题只在初始化时生效一次：云配置仅首次合入，后续导航不重复合入、不闪烁、不改写。
- 登出后主题保留：本地一份不清除。
- 主题相关的读取与保存调用符合"一次性合入 + 显式保存才写"的语义，无循环写入。

## 边界与异常

- 以下为当前已知的行为边界：登出后保留主题是设计意图，不是登录态泄漏。
