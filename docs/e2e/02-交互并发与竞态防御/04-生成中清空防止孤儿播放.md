## 用例规格

- 前置条件/夹具：`{{GUEST_FRESH}}`；mock 放慢流（`MOCK_SLOW_LLM_MS=3000`）。
- 步骤：1) 提交生成；2) 流式进行中点击「清空」；3) 等待流完成。
- UI 断言：清空后聊天为空；完成时**不得**出现无卡片的孤儿播放（浮窗不应凭空出现）。
- 音频/浏览器断言：`audio.paused` 保持 true；若自动播放发生，记为缺陷证据。
- 网络/数据断言：完成回调若触发 `tts.synthesize`，DB 中不应产生孤儿 `GenerationHistory`。
- 清理：清 cookie；必要时删除隔离库孤儿行。
- 证据要求：`ui-orphan-play.png`、`audio.json`、`db.txt`。
- 溯源：`app/(main)/chat/components/ChatLayout/index.tsx:176-178`（清空调 `resetStoryFlow`，不清全局 AbortController）；`app/services/chatFlow.ts:127`（完成回调启动播放）；`app/services/storyFlow.ts:73-115`。**待验证假设 H-05**：清空后完成回调仍会 `startStoryPlayback`。
