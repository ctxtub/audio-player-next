# 断点恢复无剩余时长时的播放状态一致性

功能域：03-播放状态与内核一致性

## 用户目标

访客带着一条"剩余可播时长为空"的播放进度回来续播时，点击播放后能从记下的段落正常出声，且浮窗标题与按钮都进入播放态，不出现"有声但界面没跟上"的分歧。

## 前置条件

- 访客首次打开站点（保留身份标识）。
- 服务端预置一条播放进度：从第 3 段起续播，服务端记下的剩余可播时长为空。

## 操作步骤

1. 刷新进入聊天页（`/chat`）。
2. 观察浮窗是否显示断点就绪（第 3/4 段）。
3. 点击播放。
4. 在播放后约 0.5 秒与约 2 秒分别观察浮窗状态与实际声音。

## 验收标准

- 播放从第 3 段文本开始（以故事卡高亮或进度徽标确认）。
- 播放时音频实际出声（`audio.paused=false`，`currentTime` 递增），且浮窗进入播放态（标题与按钮一致）。
- 以下不一致不允许出现：音频可闻，但浮窗标题显示"待创作"或按钮仍为播放图标。
- 语音合成以第 3 段文本发起请求；服务端进度查询返回该进度行。

## 边界与异常

- 剩余可播时长为空不断开"从哪段开始"：仍从服务端记下的段落（第 3 段）起播。
- 剩余时长为空时的界面播放态进入逻辑见实现参考；不得出现有声无态。
