## 用例规格

- 前置条件/夹具：`{{GUEST_FRESH}}`；输入框含 `{{E2E_PROMPT_1}}`。
- 步骤：1) 聚焦输入框；2) 在同一帧内按 Enter 并立即点击发送按钮（≤50ms 间隔，连续 3 组）。
- UI 断言：每次连击后用户气泡**仅一条**新增；不存在重复 assistant 占位。
- 音频/浏览器断言：只触发一次流式（SSE 单连接）。
- 网络/数据断言：`agent.interact` 调用次数 = 实际提交次数；DB `GuestChatMessage` 新增用户行数与 UI 一致。
- 清理：清空会话、清 cookie。
- 证据要求：`ui-double-submit.png`、`network.json`（调用计数）、`db.txt`。
- 溯源：`app/(main)/chat/components/Composer/Composer.tsx:49,64-67,115-143,160-174`（本地锁为异步 setState，存在同帧竞态窗口）。**待验证假设 H-04**：连击可绕过 `effectiveDisabled` 造成双发；运行时未复现则登记为「未复现」。
