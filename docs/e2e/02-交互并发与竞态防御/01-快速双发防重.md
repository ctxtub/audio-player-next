# 连续快速发送防重复提交

功能域：02-交互并发与竞态防御

## 用户目标

聊天输入者在极短时间内连续触发发送时，系统只发出一次生成请求，不产生重复的用户消息与重复生成，避免一次点击变成两次回答。

## 前置条件

- 访客首次打开站点（无既有身份）。
- 已打开聊天页，在输入框输入一句话。

## 操作步骤

1. 聚焦输入框，确认内容已就绪。
2. 在极短间隔内连续触发发送 3 组（回车后立刻点击发送按钮，连续重复）。
3. 观察聊天流：每次连击后新增的用户气泡数量，以及助手占位的数量。
4. 观察生成与播放：流式生成建立了几路连接，故事播放了几次。

## 验收标准

- 每次连击后，用户气泡只新增一条，不出现重复的助手占位。
- 连续点击只建立一路流式生成连接，不开启多路并发生成。
- 服务端实际处理的请求数与用户实际提交次数一致，不多出重复请求。
- 保存的用户消息行数与界面显示的用户气泡数一致。

## 边界与异常

- 连击中多余的触发被忽略，不产生报错，不影响已发出的那次生成。
- 若发送因网络或服务端原因失败，失败标记与重试行为见《失败消息重试上下文正确性》。
