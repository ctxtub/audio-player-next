# 注册中断后孤儿账号回滚删除

功能域：05-认证授权与会话生命周期

## 用户目标

注册过程中如果数据迁移中途失败，系统不留下"建了一半"的账号；用户看到明确的失败提示后，可以用同一用户名重新注册成功。

## 前置条件

- 访客身份下已有配置与聊天各至少一条（使半复制可被观测）。
- 注册使用未被占用的新用户名。

## 操作步骤

1. 填写注册信息并提交，此时迁移中途发生一次写入失败。
2. 观察注册失败提示，确认停留在登录页。
3. 故障解除后，用同一用户名再次注册。

## 验收标准

- 首次注册失败，页面给出明确的失败提示，并停留在登录页（`/auth`）。
- 失败后服务端没有该用户名的残留账号（孤儿用户被回滚删除）。
- 访客原数据未被部分搬走（不存在半复制状态）。
- 用同一用户名重试可以注册成功。

## 边界与异常

- 界面侧的失败提示行为与《注册登录校验失败提示》一致（失败原因不同，提示与停留行为一致）。
