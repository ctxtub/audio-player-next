# 访客冷启动首屏渲染

功能域：01-基础冒烟与页面基线

## 用户目标

访客第一次打开站点时，能立刻看到可用的聊天首页：问候内容、建议项、输入框与底部导航完整呈现，没有报错，可以直接开始使用。

## 前置条件

- 访客首次打开站点（无既有身份）。
- 服务可用，配置与身份接口正常。

## 操作步骤

1. 打开站点根路径 `/`，确认自动进入聊天页 `/chat`。
2. 观察首屏：聊天空态文案、问候头与建议项、输入框、底部 TabBar 完整渲染，无 JS 错误横幅。
3. 确认页面常驻一个音频元素，且处于未播放状态（冷启动不自动发声）。
4. 刷新一次页面，确认首屏仍正常渲染；首访引导只出现一次，刷新后不再弹出。

## 验收标准

- 打开 `/` 自动落到 `/chat`。
- 聊天空态文案、问候头与建议项、输入框、底部 TabBar 均正常显示。
- 页面常驻音频元素，且为暂停态（不自动播放）。
- 页面无报错横幅；控制台无未捕获异常。
- 配置接口与身份接口调用成功。
- 冷启动不产生聊天消息或故事数据。
- 刷新后首屏正常；首访引导不再重复弹出。

## 边界与异常

- 根路径自动跳到聊天页是预期行为，不是错误。
- 配置加载失败时的错误屏与重试行为见《配置初始化门控与错误屏重试》。
