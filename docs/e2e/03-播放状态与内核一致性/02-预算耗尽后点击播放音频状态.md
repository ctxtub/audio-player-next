# 预算耗尽后点击播放音频状态

功能域：03-播放状态与内核一致性

## 用户目标

剩余可播时长已经耗尽归零时，用户点击播放不会"假装播起来"：界面与实际声音保持一致，不出现"界面秒回暂停、声音却一直在响"的分歧。

## 前置条件

- 从《倒计时耗尽UI与音频一致性》的终态继续：剩余可播时长为 0，界面已显示暂停。
- 故事音频仍在响。

## 操作步骤

1. 点击"播放"按钮。
2. 在点击后短时间内（约 0.2 秒）观察界面与声音。
3. 在点击后约 1 秒时再次观察界面与声音是否一致。

## 验收标准

- 点击后约 1 秒内，界面回到暂停态（倒计时归零触发清理）。
- 以下不一致不允许出现：界面已回到暂停，但音频实际未被暂停、仍在继续响（`audio.paused=false` 且 `currentTime` 递增）。
- 点击后不产生多余的语音合成请求。

## 边界与异常

- 剩余可播时长为 0 时点击播放，不得开启一段新的有效播放；界面复位为暂停是预期行为。
- 仍有剩余时长时的正常播放不受影响。
