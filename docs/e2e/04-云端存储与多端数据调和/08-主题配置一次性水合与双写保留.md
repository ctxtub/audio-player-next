## 用例规格

- 前置条件/夹具：`{{GUEST_FRESH}}`；localStorage 预置与云侧不同的主题值（制造双写分歧起点）。
- 步骤：1) 首次加载记录主题来源（localStorage vs `config.get`）；2) 登录 `{{E2E_USER_A}}` 观察主题是否被云配置改写；3) 登出→再入访客读取主题；4) 二次导航（客户端路由）观察是否重复水合。
- UI 断言：主题一次性水合（后续导航不闪烁/不改写）；登出后主题保留（localStorage 面不清）；云配置仅在初始化时生效一次。
- 音频/浏览器断言：不适用。
- 网络/数据断言：主题相关 `config.get`/`updateMine` 调用次数符合「一次性水合 + 显式保存」语义；无循环写入。
- 清理：清 cookie/storage；删用户配置行。
- 证据要求：`ui-theme.png` ×4 时点、`network.json`。
- 溯源：`components/ThemeConfigBridge/index.tsx:32-35,41`（一次性水合 + localStorage 双写）；`app/(main)/layout.tsx:17-27`（桥挂载点）。
- 备注：登记为「刻画行为」：登出保留主题属设计意图验证，非缺陷假设。
