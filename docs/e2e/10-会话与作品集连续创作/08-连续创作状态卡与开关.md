# 连续创作状态卡、开关与剩余预算

功能域：10-会话与作品集连续创作

## 用户目标

创作页顶部展示当前集合标题；创作页提供连续创作开关、当前状态卡与剩余预算，状态与实际编排一致，用户随时可查看与关闭。

## 范围与边界声明

本场景覆盖 T2 创作页 UI 的集合标题、开关、状态卡与剩余预算（L1 + L3，含移动/桌面视觉验收）。
**明确排除**：T1 集合 CRUD、T3 单轨 timeline、T4 Library 列表视觉。

## 契约验收标准

### 1. 集合标题（collection title）
- 创作页展示当前 Collection 标题（AI 标题或用户改名后的标题）；无集合时展示空闲态。
- 标题来源与 `collection.get` 一致，不额外请求。

### 2. 开关（switch）
- 默认 `on`；切换即写 `continuousCreationStore.enabled`，并即时反映状态卡。
- 关闭后无 next job 调度。

### 3. 状态卡（status card）
- 展示状态机当前状态：`disabled` / `enabled_idle` / `generating_next` / `preparing_audio` / `next_ready` / `waiting_next` / `ended_budget` / `error`。
- 状态展示与实际编排同源，不得各自推导。

### 4. 剩余预算（remaining budget）
- 展示 `remainingMs`（人类可读，如 `12:34`）；随 audio-active 递减刷新。
- 预算耗尽展示 `ended_budget` 文案并提示可新建创作。

### 5. Artifact 卡接共享播放状态（shared playback binding）
- 聊天内 Artifact 卡展示“正在播放/已暂停”与当前 Work，与 Now Playing 共享同一播放状态源（不得各自持有独立播放实例）。

### 6. 响应式与无障碍
- 移动视口与桌面视口均可用；开关与状态卡不遮挡 Mini/TabBar。
- 开关须有可访问名称；状态卡变更以文本可读（不仅图标/颜色）。
