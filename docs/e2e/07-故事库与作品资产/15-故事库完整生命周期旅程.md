# 故事库完整生命周期旅程

功能域：07-故事库与作品资产

## 用户目标

用户在真实浏览器中完整经历故事库集合级全生命周期：在海量集合列表中体验首屏截断与滚动自动分页加载、通过关键词搜索即时过滤（命中集内作品时按集合去重）、从卡片进入真实集合详情页、在详情中重命名标题并返回列表确认标题一致同步、切换收藏状态并在收藏视图中精准呈现、在详情页执行移入回收站并验证页面自动导航离开及 Undo 撤销即时恢复、验证回收站卡片严格无详情入口且直接访问触发统一不可用保护、在回收站恢复集合至全部列表、再次软删除后触发永久删除二次确认弹窗、以及集合彻底物理删除后在全部视图、收藏视图、回收站视图与直接访问路径下的彻底不可逆消失。

## 前置条件

- 服务可用，数据库已执行必要迁移。
- 采用真实注册用户身份（`ensureRegisteredByApi`），具备独立且洁净的数据空间与充足的 API 速率配额（authedLimit = 60）。
- 通过真实 tRPC 晋升接口预先创建 22 个集合（各含 1 作品），确保跨越首屏默认单页限额（20 个）。

## 操作步骤与生命周期旅程

1. **批量集合准备（22 个）**：经真实 `conversation.createNew` + `collection.promoteArtifact` 创建 22 个集合，其中目标集合的成员作品具备特定关键词（如“小猫历险记”）。
2. **访问故事库主页首屏验证**：访问 `/library` 全部（active）视图，确认首屏仅渲染 20 张集合卡片，分页哨兵组件（InfiniteScrollSentinel）就绪。
3. **滚动加载下一页**：滚动触达底部哨兵，触发第二页拉取，确认列表增量加载至 22 张，并呈现“— 没有更多了 —”终态提示。
4. **搜索过滤（q 查询）**：在工具栏搜索框输入关键词“小猫”，验证输入防抖过滤后仅呈现目标集合卡片（服务端按 Collection 去重），清空搜索后恢复全量 22 张。
5. **进入真实集合详情页**：点击目标集合卡片标题链接，导航至 `/library/collections/{真实id}`，确认详情容器与成员列表正确渲染。
6. **重命名并验证列表标题一致同步**：在详情页点击重命名，修改标题为“勇敢小猫大冒险”并保存；点击返回故事库，确认列表视图中同 ID 集合卡片标题与服务端最终状态一致同步更新。
7. **详情页收藏集合**：再次进入该集合详情页，点击收藏按钮，确认收藏状态变更。
8. **返回列表并切换收藏视图**：返回列表并切换至“收藏”Tab，确认目标集合出现在收藏列表中。
9. **详情页移入回收站并离开**：再次进入详情页，点击“删除作品集”按钮，确认页面自动导航离开并重定向至 `/library`，同时激活全局撤销浮条（LibraryUndoToast）。
10. **执行 Undo 撤销恢复**：点击撤销浮条上的“撤销”按钮，等待恢复完成，确认集合立即重新回到全部列表。
11. **第二次移入回收站**：在列表卡片上点击“删除”，确认卡片从全部列表中移出，撤销浮条再次弹出后关闭。
12. **切换至回收站视图**：在工具栏点击“回收站”Tab，确认目标集合出现在回收站列表中，并标有“已移入回收站”状态。
13. **回收站卡片无详情入口验证**：检查回收站中目标集合卡片，确认标题为纯文本而非链接，整张卡片绝无任何 `<a>` 标签；若直接在地址栏访问 `/library/collections/{id}`，严格呈现统一不可用界面（`LibraryUnavailable`）。
14. **从回收站恢复集合**：在回收站卡片上点击“恢复”按钮，确认集合从回收站列表中移除；切换至“全部”视图，确认集合恢复可见。
15. **第三次移入回收站**：在全部列表再次点击该集合卡片“删除”，集合移入回收站；切换至“回收站”Tab 确认其存在。
16. **永久删除二次确认流**：在回收站卡片点击“永久删除”，确认弹出二次确认模态对话框；点击对话框内的“永久删除”确认按钮，完成物理删除。
17. **全维度彻底消失验证**：
    - 回收站列表无该集合；
    - 切换“全部”列表无该集合；
    - 切换“收藏”列表无该集合；
    - 直接访问 `/library/collections/{id}` 呈现统一不可用视图（`LibraryUnavailable`），绝不展示任何集合数据。

## 验收标准

- 所有数据流转全量走真实 API 与真实 DOM 事件，严格零 mock 核心逻辑。
- 首屏 20 张与滚动加载 22 张行为完全符合服务端游标分页与无限滚动契约。
- 详情 Rename 后返回列表，标题与服务端最终状态一致（opaque 分页元数据无损与内部缓存策略由单元测试覆盖）。
- 详情软删除触发自动导航离开（离开 `/library/collections/[id]`），Undo Toast 跨路由生命周期留存且支持安全撤销。
- 回收站视图中严格杜绝详情入口；直接访问软删除/已删除集合路由严格呈现统一不可用页面，杜绝存在性探测。
- 永久删除严格遵循二次确认流，未确认前零网络请求，确认后不可逆物理清除。
- 全程控制台无未捕获异常与系统级报错。
