# 创作、作品集与连续播放契约

本规范收敛已实施的创作完整旅程、首篇自动播放过渡和作品集切曲方案。测试与交付口径以 [测试入口](../testing/README.md) 为准；首次作品集标题另见 [标题规范](2026-09-22-first-collection-title.md)。

## 内容与播放身份

正式身份链为 `Conversation → StoryCollection → StoryWork → StoryAudioAsset → PlaybackSession(source.workId)`。未晋升为 Work 的正文可以显示草稿，但不得以临时 URL、消息 ID 或段落序号进入正式播放队列。

一条作品只有一条完整音频和一条连续时间轴，播放器标为“播放进度”；旧草稿兼容路径才使用“本段”。内部 TTS 分块全部成功后才发布资产；部分失败不得发布不完整音频。新作品默认采用单轨正式路径，不依赖发布或浏览器覆盖开关。旧分段数据仅保留兼容读取，物理退役需单独方案与数据授权。

## 首篇与作品卡

- 首篇作品晋升后自动准备并播放；从自动播放承诺到真正起播，卡片显示“正在准备语音”且不可重复点击。
- 同一 Work 的准备或自动播放请求幂等，不重复合成、resume 或驱动 Transport。
- 文本与消息交付完成后输入框解除提交锁，保存、TTS 和后台自动播放不继续占用“发送中”。空输入仍禁用发送按钮。
- 已完成卡片是原位播放入口，表达播放、准备、暂停、失败重试、缓存过期与播放完成；查看全文为次级操作。
- 当前卡片按正式 workId 匹配共享会话，播放与资产状态来自正式 projection，进度来源于共享时间轴；未知时长不伪造百分比。准备与切换保持布局稳定，沿用 Design Token，动效尊重 `prefers-reduced-motion`。

## 切曲与页面连续性

作品集详情中快速切换采用最新目标优先，仅最新作品显示准备状态。切曲先暂停旧音频，旧请求不能起播或覆盖新请求的 UI。主导航切换保留有效内存会话与真实播放状态；整页刷新恢复为暂停态，继续播放使用已保存的合法进度。播放完成后的重播从开头开始，迟到的旧 session 进度不得覆盖新 session。

创作页、故事库、详情、Mini 和 Expanded 的主要上下文使用同一作品集标题，副标题表达当前作品。手动改名不得被自动标题覆盖。移动与桌面布局需避让真实 Mini、Composer、TabBar 和设备安全区，列表末卡可完整滚入可见区。

## 连续创作

- 默认开启，采用会话启动时的播放预算快照；只预备一个正式下一作品。
- 下一篇经历生成、保存 Work、准备音频与 ready，并在内容流展示阶段卡；错误提供重试和关闭操作。
- 当前故事结束时，ready 下一篇立即续播；尚未 ready 时显示等待，准备完成后自动续播。
- 预算只按实际音频推进递减；暂停、缓冲、生成、保存、TTS 和等待不扣预算。
- 预算耗尽立即停声、保存进度、取消下一任务；终态后不再新增或播放作品。
- 关闭连续创作取消未完成下一篇任务、清除阶段卡，迟到结果不得再自动续播。
- 用户输入、新建创作、切集合及登出取消相关在途任务；旧 epoch、会话或集合结果不得恢复旧卡片或起播。

## 新建创作与缓存

新建创作保留已完成作品集，立即停声并卸载媒体，清空当前高亮、准备、下一篇、错误与重试状态，回到空对话、“新作品集”、默认连续开启及新预算快照。旧异步响应不得写入新集合。

资产采用三十天滑动缓存；过期仅删除音频，不删除作品、集合或进度，重播按原 profile 重新准备。生成中、播放中及有效租约资产不能被清理。客户端每十秒节流保存，暂停、切曲、页面隐藏与结束强制保存；资源保护见 [运行时规范](2026-09-23-runtime-hygiene-and-request-guards.md)。

## 可见 UI 验收

交付最后阶段在隔离 production build、默认发布配置下复用四条现有用户旅程：

- 同一会话两篇故事播放与连续开关交接：首篇准备态与输入解锁、标题落地、播放暂停继续、重播刷新恢复及自动交接。
- 连续创作下一篇准备与自动续播：生成/保存/语音/ready、等待期间预算不减、无人点击续播及真实预算耗尽终态。
- 集合详情起播跨页播放：快速切曲、标题一致、改名、暂停刷新恢复、跨 Tab 持续播放及安全区。
- 播放与准备中新创作强重置：立即回到初始态、旧结果不复活、已完成作品集保留。

验收只由页面可见操作与结果证明，不调用 Store、状态机或业务内部入口，不注入功能开关或预造本轮作品/播放状态。默认 Chromium；出现明确 WebKit 兼容风险时补跑受影响旅程。代表性视觉检查覆盖窄屏、桌面、亮暗主题、长标题、准备/等待状态和 Mini/底栏遮挡。
