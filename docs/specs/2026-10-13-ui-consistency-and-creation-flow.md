# 界面一致性与创作动线

## 目标与范围

基于 2026-10-13 内置浏览器实际图片复评，修复手机创作空白、设置文字断行、悬浮播放器遮挡、按钮和链接样式混用及播放结束态表达；同时完成已确认的直接续写与共享功能状态说明。沿用现有亮暗主题、书籍标题层级和主导航，不扩展生成供应商、账号或作品持久化契约。

## 用户可见规则

- 手机创作状态卡按内容高度排列，开关与时长不产生无内容的固定高空白。375×812 下正常标题的控制卡目标不超过 260px；长标题/放大文字自然换行，不能用裁切达标。功能说明可折叠，重置时长仍可发现。
- 创作页与设置页统一称为“自动播放与连续创作”，共用已有配置。关闭时说明当前未启用、已保存故事可手动收听；时长展示为偏好，不将剩余预算表达为正在生效。开启后的实际播放扣减、暂停不扣、耗尽需重置、刷新继承规则继续适用。
- 手机设置页的主题选项按自然短语阅读，不逐字竖排；访客说明使用可读的整行宽度，头像和注册动作不挤成窄列。亮暗主题和键盘选择均可用。
- 迷你播放器默认位置避让设置开关、播放/管理动作和创作输入。桌面仍保留悬浮偏好和拖动能力；统一页面与播放器的安全区域，不为每页添加不同的固定补丁。显式拖动保留用户控制，跨页的默认/停靠位置不能阻断主操作。手机输入与底部导航仍可用。
- 展开播放器的“查看故事集”“查看创作记录”“查看正文”采用同级主题化控件，亮暗主题不出现遗漏样式的白色默认按钮。返回与查看记录链接在访问前后均可辨识，并与相邻页面的次级导航一致。
- 播放结束时，展开播放器的中央主按钮可直接“重新播放”；从头播放与重播共用既有业务入口。不再提示返回 Mini 才能重播；关闭提示按当前播放状态表达，不在暂停/结束时声称播放继续。暂停、续听、切篇、单轨断点与音频会话身份保持原契约。
- 故事库卡片将收听作为清晰的主动作；管理与删除为次级操作。主次按钮使用稳定的字号、触控高度和主题样式，不强制把书籍标题改为品牌标题。
- 故事集提供直接“续写这个故事集”，保留独立“查看创作记录”。直接续写复用已有恢复流程：当前草稿需确认并保留，等待当前生成及保存完成，成功后绑定目标会话并进入创作；不会自动生成故事。只读记录页仍只读，其恢复按钮与直接入口共用流程，避免复制两套切换逻辑。

## 实施约束

按手机创作/设置、播放器/Chrome、故事库/续写划分不相交所有权。先完成各自实现和窄验证，再停止写入并独立审查；发现问题返回原实现者修复。过程证据写入 `.e2e-results/ui-consistency-repairs-2026-10-13/`。

保持当前分支和基线 `827b141`，不读取真实环境文件或用户数据。所有浏览器服务使用独立临时数据库、随机本地端口和本地 mock。只在全部实现收口后执行用户视角浏览器验收，不注入 Store、内部入口或发布开关。

## 完成验证

运行 `yarn test:fast`、隔离 production `yarn build`、`git diff --check`。复用连续创作、故事库管理续听、新建强重置和设置/播放交接旅程，补齐直接续写与结束重播的可见 UI 步骤。内置浏览器在 375×812 与 1280×720 下亲自查看亮暗主题截图，对照原始图片；同时检查手机输入、默认悬浮避让、键盘开关、自然播放完成与直接续写草稿确认。

只有独立审查、工程门、受影响用户旅程与实际图片复验通过后完成本地提交。远端发布另行授权。
