# 桌面悬浮拖拽吸附与 M6 收官（M6-04 Desktop Floating Mode）

功能域：01-基础冒烟与页面基线

## 用户目标

桌面端（viewport≥768）且偏好开启时 Mini 为可拖动悬浮窗：默认右下、仅 Grip 可拖、拖拽不出界、释放吸附最近水平边、缩窗自动回 clamp；偏好关闭时 Mini 仍固定在 TabBar 上方（wide-docked，不消失）；跨 768 往返同一 Session、drag 坐标不残留非法值；刷新回默认右下（位置仅内存态）。

## 前置条件

- M5 PlaybackSessionStore + Transport 为唯一播放事实源（M5 冻结）；浮动位置为纯 presentation，不 mutation session/transport。
- M6-01 冻结断点（767→compact，768→wide）与三态形态；M6-02 语义核心（标题/动作/进度）与 entry 契约；M6-03 MainChrome 预留与键盘抑制。
- `@use-gesture/react useDrag ^10.3.1` 仅绑定 DragGrip；Playback/Metadata 按钮不参与 drag。

## 操作步骤

1. 建立 Work 播放会话并暂停驻留（真实 `beginSession` + 首段合成 + pause），视口 1280×800、偏好开启：Mini 为 `wide-floating`，默认右下（right `var(--space-4)`、bottom `tab-bar-safe-bottom + space-4`），`data-dragged=false`，Grip 可见。
2. 拖 Grip 向左大幅移动后释放：Mini 不出界，吸附左或右最近水平边（垂直保留），`data-dragged=true`，Playback/Metadata 点击仍正常（不触发 drag）。
3. 拖 Grip 越界（往视口外）后释放：Mini 仍完全可见（clamp）。
4. 缩窗（如 1280→800）：Mini 自动 re-clamp，仍完全可见，同一 `sessionId`。
5. 经设置页关闭「桌面悬浮播放」：同一 Session 下 Mini 切为 `wide-docked`，固定 TabBar 上方、Grip 消失、拖拽不移动、BottomChrome 重新预留。
6. 跨 768 往返（1280→767→1280）：767 为 `compact-docked`（Grip 消失、坐标不参与布局），回 1280 恢复 `wide-floating`（或 `wide-docked`，依偏好），同一 `sessionId`、无非法坐标。
7. 刷新页面：Mini 回默认右下（`data-dragged=false`），同一 Work 可恢复 `ready` 会话（M5 Anchor），位置不跨刷新持久化。

## 验收标准

- ≥768 + pref true → `wide-floating`（`position:fixed`、`width:var(--size-mini-now-playing-wide)`、`z-index:var(--z-floating)`）；默认右下 CSS，无固定像素初始化。
- Grip-only drag：仅 `mini-drag-grip` 绑定 `useDrag`（`filterTaps:true`）；Playback/Metadata 不参与。
- drag 期间/结束 clamp 到 viewport 内；结束吸附最近水平边，垂直保留。
- `window.resize + visualViewport.resize` 后 re-clamp，不跑出屏幕。
- 位置仅内存态：不写 DB/UserConfig/localStorage；reload 回默认右下。
- pref false → `wide-docked`（固定 TabBar 上方，预留；Mini 不消失）。
- 跨 768 往返同一 Session，drag 状态不残留非法坐标。
- 纯 presentation：不 mutation session/transport；液态玻璃视觉不变。

## 边界与异常

- 视口小于面板时 clamp 回退为边距左上对齐，不抛非法坐标。
- `prefers-reduced-motion` 下关闭 snap 过渡。
- Playwright 以 mouse 拖 Grip 模拟 pointer drag（Chromium/WebKit 双跑，不重试）。
- 旧 `components/FloatingPlayer` 适配器已删除；`isFloatingVisible/show/hide` 已从 Transport 删除（`useFloatingPlayer` 仅保留 play/resume/pause）。
