# 工具链与作品播放快照

## 范围

统一本地、CI 和镜像的 Node 22 工具链，使用 Sass 模块语法替代过时的 import，保持生成 CSS 不变。正式作品始终播放单轨 Asset，草稿仍使用临时音频；删除没有调用者的客户端分段音频门面与发布开关。

作品详情读取在所有权校验后返回 playbackSnapshot，包含 paragraphs、segmentationVersion 和 totalParagraphs。播放恢复和草稿晋升直接消费这一快照，不再调用分段音频 Manifest API。服务端开始、完成、晋升也消费同一解析器：已有旧 Manifest 时保留冻结版本与段落数量，按索引读取冻结文本；不存在时按现有正文切分。冻结段落缺失或索引不连续也视为不可解析，不能回落成新的身份。读取失败必须保留 Anchor 和进度，可重试，不将未知状态当作作品不存在；错误状态下当前草稿 Blob 结束也不得写整篇完成进度或交接下一篇。

旧段落索引与正式音频毫秒进度分别保留，不进行无法证明精度的换算。旧 Manifest、Segment、授权路由、迁移和对象回收适配器继续保留，避免丢失历史对象引用。访客单轨 Asset 和毫秒进度迁移、注册回滚与草稿 Blob 交接遵循[注册迁移契约](2026-10-07-guest-single-track-migration.md)。

## 验收

- Sass 迁移前后编译 CSS 相同，弃用告警消失。
- Node 22 下静态检查和隔离 production build 成功。
- 用户和访客作品的详情快照与服务端身份写入使用相同版本及数量；缺失 Manifest 合法回落，读取失败不清 Anchor。
- 单轨播放、暂停恢复、重新播放、草稿晋升与已有毫秒进度语义保持；旧数据迁移和回收实现不删除。

运行环境验收由用户执行。本次不修改分布式限流、不操作生产数据、不物理退役旧表或旧对象；发布需另有授权。浏览器运行验收由用户接手，本次只记录工程验证证据，不代替用户验收。
