## 用例规格

- 前置条件/夹具：在单会话内完成播放构建（直接生成短文本故事或通过 seed 水合活跃播放状态）；`{{E2E_PORT}}` 服务与 mock 上游正常。
- 步骤：1) 在 `/chat` 启动播放并读取浮窗与故事卡状态；2) 客户端路由切 `/player` 读取全屏播放器大按钮与进度条/段落徽标；3) 客户端路由切 `/setting` 验证浮窗常驻；4) 客户端路由回跳 `/chat` 再读一次播放时间。
- UI 断言：
  1. `/chat` 界面：浮窗优先且正确渲染倒计时标签（`remainingTimeLabel`，如 `29:xx`）与暂停图标；故事卡播放按钮处于「暂停播放」状态（不得在 `/chat` 浮窗强行断言 `第 1/4 段` 段落徽标，该行为已被组件代码证实物理互斥）；
  2. `/player` 界面：全屏大播放器按钮显示暂停态，段落指示徽标正常渲染 `第 1 / 4 段`（或 `第 1 / 4 段 就绪`）；
  3. `/setting` 界面：浮窗常驻挂载且暂停键状态与播放中一致。
- 音频/浏览器断言：跨路由导航（`/chat` → `/player` → `/setting` → `/chat`）期间，`audio.paused === false`，音频 `currentTime` 保持单调递增，播放无打断、无重置、无卡死。
- 网络/数据断言：跨页面路由切换过程中，无多余或重复的 `tts.synthesize`/`agent.interact` 调用（仅复用既有音轨与会话）。
- 容错与退出：配置 503/429 弹性退避重试（静默等待 60s，重试 ≤ 3 次）；执行完成产出完整 `report.md` 与终端 VERDICT 后以 exit 0 退出。
- 清理：清空会话与浏览器上下文。
