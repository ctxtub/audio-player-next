# 自动续写期间输入框草稿保留

功能域：02-交互并发与竞态防御

## 用户目标

播放器在后台自动续写故事时，用户正在输入框里打的字不丢失，续写结束后草稿原样还在。

## 前置条件

- 访客首次打开站点（无既有身份）。
- 先完成一次故事生成，正在播放故事，自动续写即将触发（同《预载续写不污染聊天流》的播放条件）。

## 操作步骤

1. 在自动续写触发前，在输入框输入一句话作为草稿，不发送。
2. 等待自动续写发生。
3. 查看输入框内容是否完整保留。

## 验收标准

- 输入框中的草稿完整保留，不被清空；预期不发生自动续写清空用户草稿。

## 边界与异常

- 本场景只覆盖自动续写触发的情形；聊天流侧的隔离行为见《预载续写不污染聊天流》。
- 用户主动发送后输入框清空，属于正常发送行为，不在本场景内。
