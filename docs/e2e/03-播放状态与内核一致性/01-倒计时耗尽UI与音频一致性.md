# 倒计时耗尽UI与音频一致性

功能域：03-播放状态与内核一致性

## 用户目标

访客播放故事时，可用播放时长（倒计时/预算）耗尽后，界面显示的状态要和实际声音一致；不出现"界面已显示暂停、声音却还在响"的声画分歧。

## 前置条件

- 访客首次打开站点。
- 服务端预置一条播放进度：从第 1 段起播，剩余可播时长约 3 秒，指向一个 4 段故事。
- 已冷启动进入播放页（`/player`），浮窗显示断点就绪。

## 操作步骤

1. 点击播放，故事从第 1 段开始播放。
2. 在耗尽前、耗尽时、耗尽后分别观察播放按钮、倒计时显示和实际声音。
3. 观察当前段落是否播完自然结束，以及耗尽期间是否有新的预载请求。

## 验收标准

- 预算耗尽后，播放按钮回到"播放"图标（非播放态），倒计时隐藏或归零。
- 以下不一致不允许出现：界面已显示暂停（按钮为播放图标），但音频实际仍在响（`audio.paused=false` 且 `currentTime` 递增）。
- 当前播放的段落在播完自然结束前不得被中途打断。
- 耗尽期间不再触发新的预载与语音合成请求（仅播放态触发预载）。

## 边界与异常

- 预算耗尽后再次点击播放的行为见《预算耗尽后点击播放音频状态》。
- 预算耗尽瞬间"音频应立即停还是播完当前段"与"声画一致"要求之间的取舍待产品确认（见回告清单）。
