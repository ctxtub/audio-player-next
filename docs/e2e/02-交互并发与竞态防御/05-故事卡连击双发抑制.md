# 故事卡连击双发抑制

功能域：02-交互并发与竞态防御

## 用户目标

用户快速连点故事卡上的"播放故事"时，播放状态收敛到唯一终态，只有一路声音，不出现按钮闪烁或两卡同播。

## 前置条件

- 访客首次打开站点（无既有身份）。
- 先完成一次故事生成，聊天页已有已完成的故事卡。

## 操作步骤

1. 快速双击故事卡上的"播放故事"（两次点击间隔极短）。
2. 重复上述双击 3 次。
3. 观察按钮终态是否稳定，有无多张卡片同时标记播放中。
4. 听实际声音，确认只有一路在播。

## 验收标准

- 按钮终态稳定为"暂停"或"播放"之一，不闪烁。
- 没有两张卡片同时标记为播放中。
- 连击中可能短暂触发多次语音合成请求，但最终只有一路音频在播（音频来源唯一）。
- 播放进度不出现重复异常写入。
- 连击结束后播放状态收敛到唯一终态，最后一次操作生效。

## 边界与异常

- 连击过程中的短暂中间态允许存在，以连击结束后的终态为准。
- 若播放因合成失败而停止，失败行为见《语音合成失败时停声不残留》。
