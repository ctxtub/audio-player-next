## 用例规格

- 前置条件/夹具：`{{GUEST_FRESH}}`；播放由 chat 卡片发起且临近段尾（mock 控制音频 ≈2s 触发 near-end 预载）。
- 步骤：1) 播放故事；2) 临近段尾前在输入框预置文本 `{{E2E_PROMPT_3}}`（不发送）；3) 等待预载续写触发。
- UI 断言：聊天流中**不应出现**「请继续故事」用户气泡（预载不应可视）；若出现，记为缺陷证据。
- 音频/浏览器断言：预载完成后段落衔接正常（见 E2E-03-11）。
- 网络/数据断言：`agent.interact`（预载）发生但 `generationHistory` **不新增**记录（recordHistory=false）；`chat.saveConversation` 若被触发，不得把「请继续故事」持久化。
- 清理：清空会话。
- 证据要求：`ui-preload-pollution.png`、`db.txt`（GenerationHistory 计数）。
- 溯源：`stores/preloadStore.ts:84-150`（:93 `beginChatStream(AUTO_CONTINUE_PROMPT,{recordHistory:false})`）；`app/services/chatFlow.ts:16,187-209`；`stores/chatStore.ts:219-232`（`user.submit` 会写 `inputValue:''` 并入流）。**待验证假设 H-03**：预载续写以正常用户消息身份进入聊天流。
