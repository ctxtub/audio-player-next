# 新建创作强重置

功能域：10-会话与作品集连续创作

## 用户目标

点击「新建创作」后，旧会话的生成、续作与音频全部停止，Chat 与 Now Playing 回到 idle，进入一个全新的空会话；旧作品集仍可在故事库回访。

## 范围与边界声明

本场景覆盖 T2 唯一 `startNewCreation()` 的强重置语义（L1 + L2 + L3）。
**明确排除**：T4 Library UI 的集合删除与契约迁移。

## 契约验收标准

### 1. 唯一入口（single entry）
- 全产品只有一个 `startNewCreation()`；确认 UI 只调用它，不得各自直接 abort/reset。

### 2. 强重置序列（ordered reset）
按顺序：对草稿/在途生成/未保存 Artifact 确认 → `epoch++` 使旧回调失效 → abort generation/promotion/continuous job/audio ensure → pause + unload audio、revoke Blob、clear Playback Session/Anchor → reset preload/generation/Now Playing/message runtime → `createNew(expectedOldId)` → 初始态。

### 3. 旧响应不复活（stale callbacks inert）
- `epoch++` 后，旧 generation/promotion/audio/continuation 回调一律 no-op，不得写回消息、不得播放。
- 停止音频后不得有任何自动续播。

### 4. 初始态与预算（initial state）
- Chat 消息清空；Now Playing 回到 idle（无 source、无 timeline）。
- 连续创作默认 enabled；预算按当前设置重新快照。

### 5. 旧集合可回访（no destructive reset）
- “新建创作”只重置当前会话，不删除旧 Collection/Work；旧集合仍可在故事库打开与播放。

### 6. 远端失败安全（fail safe）
- `createNew` 远端失败时保持无声安全态并允许重试，绝不恢复旧播放。
