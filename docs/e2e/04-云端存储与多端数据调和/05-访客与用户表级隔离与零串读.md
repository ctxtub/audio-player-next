# 访客与用户表级隔离与零串读

功能域：04-云端存储与多端数据调和

## 用户目标

访客试用产生的数据只属于访客；注册登录后，数据落到账号名下，访客数据与账号数据分开存放、互不可见；账号 A 的任何内容在账号 B 下都看不到。

## 前置条件

- 全新访客身份，尚未登录。
- 账号 A、账号 B 可用。

## 操作步骤

1. 以访客身份使用产品：产生配置、聊天、播放进度各至少一条。
2. 注册并登录账号 A。
3. 对比访客侧与账号侧的数据行：访客表（`Guest*`）与账号表（`User*`）。
4. 再登录账号 B，读取可见内容。

## 验收标准

- 登录后界面显示迁移后的账号数据。
- 迁移后新的写入全部落到账号表（`UserPlaybackProgress` / `ChatMessage` / `UserConfig`）；访客表旧行仅作为待回收遗留，不再写入。
- 账号 B 下看不到账号 A 的任何内容：两账号之间无共享主键、无串读；播放进度按访客 / 账号分开存放。

## 边界与异常

- 迁移时的数据保真细节（段落序号、内容分片、创建时间）见《访客→注册三步迁移与数据保真》。
