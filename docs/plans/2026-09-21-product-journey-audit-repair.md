## 执行规则

按下列顺序串行处理。每项先确认生产调用链和用户可见结果；符合要求则记录通过而不改代码，有问题才修复。每次修复独立提交，并执行受影响范围的最小验证与 `git diff --check`。浏览器旅程只在全部功能收口后运行。

## 排程

| 顺序 | 审计目标 | 完成标准 |
|---|---|---|
| 播放身份与完整音频 | 检查生成完成、晋升、首播、重播和自动续播是否全部以正式 `StoryWork` 为身份 | 用户听到的完整作品只有一个 Work、一个 Asset、一条连续时间轴 |
| 创作页作品卡 | 检查 idle、preparing、playing、paused、error、expired、ended 及并发点击 | 所有状态来自正式 projection，失败和过期可恢复 |
| 音频资产生命周期 | 检查原子发布、复用、进度、刷新恢复、过期重建、租约与清理 | 单轨路径在默认发布配置下完整闭环 |
| 连续创作预算 | 检查实际播放扣减、暂停/缓冲/等待不扣、耗尽停止 | 预算按真实播放时间递减，归零立即停止并取消下一篇 |
| 下一作品交接 | 检查生成、保存、音频准备、waiting、ready、自动续播、失败重试 | 下一篇始终是正式 Work，所有状态和恢复操作有效 |
| 新建创作与取消 | 检查立即停声、在途取消、迟到结果、远端失败和重复点击 | 确认后立即回到安全初始态，旧结果不能复活 |
| 故事库列表 | 检查集合信息层级、交互、空态、加载、撤销、Mini 与安全区 | 移动和桌面均符合现有视觉体系且无遮挡 |
| 作品集详情 | 检查成员列表、播放状态、重命名、收藏、删除和响应式布局 | 不出现原生未样式化控件，当前 Work 状态一致 |
| 全局播放器与跨页恢复 | 检查标题、作品位置、进度、刷新、跨页和 Expanded | Chat、Library、Mini、Expanded 展示同一身份和进度 |
| 最终用户验收 | 清理旅程口径并检查移动、桌面、亮色、暗色、长文案和遮挡 | 四条真实旅程及代表性视觉检查通过 |
