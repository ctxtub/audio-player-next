# 注册迁移与草稿音频交接

## 当前契约

注册时，用户创建、访客配置、会话、作品集、聊天、作品映射、旧音频及单轨 Asset 归属转移、Anchor 和两类进度迁移在同一数据库事务完成。密码计算和 Cookie store 获取在事务前；事务内不调用 TTS、对象存储或外部网络。任何数据冲突或有效合成租约导致整个事务回滚，访客原数据与音频引用保留。

单轨 Asset 的 id、storageKey、冻结身份、音频 metadata 与时间戳原样转移，不复制对象或重新合成。目标同作品同世代已存在时，仅完整音频语义与对象引用等价才幂等完成；不等价则拒绝。等价复用保留两侧最新真实访问时间，避免丢失访客近期读取而提前回收对象。有效 preparing 租约禁止转移；过期租约清除，后续可正常重新 claim。成功后移除访客 Asset 引用，访客 GC 不得删除已转给用户的对象。

毫秒进度按已校验的作品映射复制，保留 positionMs、durationMs、完成历史与时间戳。目标已有记录时保留用户记录，不用访客旧高位覆盖后来重播的零位置。当前作品的进度 sessionId 与迁移后 Anchor 对齐；访客进度原行保留到 GC。重复迁移不重复建作品、音频或倒退用户进度，未映射或非本主体作品不迁移；已迁给其他账户的会话或作品集拒绝复用，防止同访客身份重复注册产生跨账户引用。Anchor 的 timer 模式与预算原样迁移。

数据库提交后才写登录 Cookie。若写 Cookie 失败，保留已注册账户及迁移数据，返回“注册已完成，请使用刚设置的账号密码登录”；不得删除已提交用户。登录现有账户不触发访客迁移。

草稿晋升时当前 Blob 不打断。该 Blob 的时间与结束事件不能表示正式单轨进度：结束后停在 ready，不写整篇完成、不自动交接下一作品。下一次显式播放请求正式 Asset，按已有毫秒进度恢复；没有毫秒进度从完整单轨开头播放，不将旧段落索引换算为时间。作品快照失败继续保留 error，可重试。

## 工程验收

独立临时数据库验证完整注册路径、归属/对象 key 保持、旧新音频共存、幂等、冲突与活动租约回滚、重播零位置保护、未映射/异主体隔离、timer 保留与 Cookie 失败后的账户保留。客户端窄测验证晋升 Blob 的暂停、自然结束、失败和之后显式 Asset 播放；不得把这些窄测当成 UI 运行验收。

运行验收由用户承担；本轮不运行浏览器验收、不操作生产、不删除旧表或历史对象、不修改分布式限流。工程收口执行 test:fast、隔离 production build、diff 检查及独立 review，之后显式提交授权文件。
