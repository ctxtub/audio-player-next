## 用例规格

- 前置条件/夹具：延续 E2E-03-01 终态（预算 0、音频仍在播）。
- 步骤：1) 点击「播放」；2) 采样点击后 0.2s/1.2s 的 UI 与音频。
- UI 断言：1.2s 时 UI 已回到暂停态（倒计时 0 触发 tick 清理）。
- 音频/浏览器断言：音频实际未被暂停且继续响——不一致即为缺陷证据。
- 网络/数据断言：无多余 `tts.synthesize`。
- 清理：同 E2E-03-01。
- 证据要求：`audio.json`、`console.json`。
- 溯源：`stores/playbackStore.ts:250`（`start()` 仅判 `remainingMs===null`，0 值可入）；`:189-216`（1s 内 tick 复位）。
