## 用例规格

- 前置条件/夹具：`{{GUEST_FRESH}}`；mock 上游 `MOCK_SLOW_LLM_MS=3000` 放慢流 A。
- 步骤：1) 提交流 A；2) 流式进行中提交流 B（内容 `{{E2E_PROMPT_2}}`）。
- UI 断言：**B 的用户气泡不得消失**；最终应保留 B 的完整回复；无「两条 sending 同时存在」或两者全消失的终态。
- 音频/浏览器断言：仅最后完成的故事触发自动播放；不出现旧流文本混入 B 卡片。
- 网络/数据断言：流 A 被中止（abort）；`chat.saveConversation` 快照与 UI 一致（不含被清掉的消息）。
- 清理：清空会话；恢复 mock 延时。
- 证据要求：`ui-overlap.png`、`console.json`（abort 记录）、`db.txt`。
- 溯源：`app/services/chatFlow.ts:33,47-50,155,165,178`（全局单 AbortController）；`stores/chatStore.ts:505-512`（`resetActiveSession` 移除全部 sending，可能误删新流占位）；`stores/chatStore.ts:262-286`（delta 落空）。**待验证假设 H-02**：旧流的中止处理会清掉新提交的用户消息。
