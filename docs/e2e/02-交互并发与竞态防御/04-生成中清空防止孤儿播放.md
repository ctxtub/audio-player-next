# 生成中清空防止孤儿播放

功能域：02-交互并发与竞态防御

## 用户目标

故事还在生成时，用户清空聊天，之后不会有找不到归属故事卡的播放突然响起，界面与声音都保持干净。

## 前置条件

- 访客首次打开站点（无既有身份）。
- 当上游大模型响应变慢时（生成需要等待，便于在流式过程中执行清空）。

## 操作步骤

1. 在输入框输入一句话并发送，等待流式生成开始。
2. 在流式生成过程中点击"清空"。
3. 确认聊天已为空。
4. 等待原生成在后台结束，观察聊天界面是否多出内容、浮窗是否出现、有无声音响起。

## 验收标准

- 点击清空后，聊天为空。
- 生成结束后，不出现无归属故事卡的播放；预期不发生浮窗凭空出现。
- 音频保持暂停，没有自动响起的声音。
- 即使旧生成的完成回调在后台触发了语音合成，也不产生无归属的生成历史记录。
- 清空后，之前生成的完成回调预期不再启动播放。

## 边界与异常

- 旧请求可能仍在后台跑完，但其结果不写入聊天、不触发播放、不新增生成历史。
- 清空后发起的新对话不受旧生成影响，按正常流程生成与播放。
